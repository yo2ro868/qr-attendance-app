# 出勤・休暇管理データ の作成スクリプト

出勤管理システムの「Excel出力」と職員名簿を照合し、月次一覧・令和〇年出勤簿・年次休暇などを作るためのブック
`出勤・休暇管理データ.xlsm` を作り直すスクリプトです。ブックには氏名が入るため、`.xlsm` は Git に含めません（`.gitignore`）。

## 必要なもの

- Python 3 と openpyxl（`pip install openpyxl`）
- Microsoft Excel（最後に Excel で再計算して保存するため）

## 作り直し方

プロジェクトのフォルダで次を実行すると、プロジェクト直下に `出勤・休暇管理データ.xlsm` と `出勤・休暇管理データのマクロ.bas` ができます。最初に一度、Excel で開いて［Alt+F11］→［ファイル］→［ファイルのインポート］で .bas を取り込みます（VBA はスクリプトから入れられないため）（同じ名前のファイルは上書きされます）。

```
powershell -ExecutionPolicy Bypass -File tools\matching_excel\build.ps1
```

別の場所に作るときは `-Out` で出力先を指定します。

**作り直したブックは空の様式です。** 使っているブックの職員名簿・休暇等（旧 年次休暇）などの入力内容は、新しいブックに貼り付け直してください。

## ファイル

| ファイル | 内容 |
|---|---|
| `make_matching.py` | ブックの様式と計算式を作る本体（シート構成・休暇の計算ルールもここ） |
| `add_ignored_errors.py` | 入力欄の「数値が文字列として保存されています」警告を出さない設定を入れる |
| `add_buttons.ps1` | ［申請を取り込む］ボタンを付けて .xlsm で保存し、.bas を同じフォルダに置く |
| `macro\出勤・休暇管理データのマクロ.bas` | ボタンのマクロ（読み直して件数を表示。未保存の休暇申請シートは保存するか聞く）。このPCでは動かして確かめていない |
| `add_queries.ps1` | 休暇申請シート（tools/leave_sheet）を読む Power Query を入れ、「休暇申請シートの読み込み」シートに表を作る（開いたときに読み直す設定） |
| `queries\*.pq` | 休暇申請シートから作る表：年休_自動（ID\|年 ごとの年次休暇の使用・分）、月別_自動（病気・看護の月ごと）、日別_自動（出勤簿の日ごとの欄の文字） |
| `finalize.ps1` | Excel で再計算して保存する |
| `build.ps1` | 上を順に実行する（`-Folder` を付けると、そのフォルダの休暇申請シートを読んだ状態で作る。確認用） |

## 休暇の計算ルール（make_matching.py の先頭の定数）

- 年次休暇の1日は7時間45分（`DAY_MIN = 465`）。15分単位。
- 本年分：入力があればその日数、採用日・退職日があれば在職期間に応じた日数（`PRORATED`）、どちらもなければ20日（`GRANT_DEFAULT`）。
- 繰越分：前年の翌年繰越。前年の行がない年（活用開始時）だけ日数を手入力し、1日未満は切り捨て・上限20日。
- 合計：繰越分＋本年分（上限40日、`TOTAL_MAX`）。
- 翌年繰越：残り（合計−本年使用）の1日未満を切り捨て、上限20日（`CARRY_MAX`）。繰越分と本年分は区別しない。
- 病気休暇・看護休暇は分単位（時間:分）。出勤簿には各月と1月からの累計を表示。
- 土日・祝日（祝日シート）・年末年始（12/29〜1/3）は同じ色。

## 休暇申請シート・Forms の読み込み

- 「休暇申請シートの読み込み」シートの B2〜B4 に、休暇申請シートのフォルダ、休暇申請フォーム・休暇承認フォームの回答の Excel（「Excel 用 Forms」で作り、OneDrive で同期したもの）の場所を入れる。名前「フォルダ」「Forms申請ファイル」「Forms承認ファイル」。
- Forms申請.pq：回答者のメールアドレスを職員名簿の C 列（名前「職員名簿表」）で出勤用ID にする。列は質問の文（見出し）で探す（完全一致 → 前方一致）。Forms承認.pq の回答を キー（出勤用ID|開始日|休暇の種類）で当てはめ、いちばん新しい回答を使う。
- 申請データ.pq ＝ 休暇申請シート（leave_sheet の 申請データ.pq を「申請データ_用紙」の名前で入れる）＋ Forms申請。年休_自動 は Forms の分（Forms分）も出し、計算用 W 列に入る（マクロが休暇申請シートに書く調整に足す）。
- 「申請一覧」シート：休暇申請シートと Forms の全員の申請と状況。先頭に、読み取れない休暇申請シートと、合う申請がない承認の回答。
- 読み込んだ表は「休暇申請シートの読み込み」シートの8行目が見出し、6行目が行数。年休_自動 A列、月別_自動 E列、日別_自動 S列から。

- 「休暇申請シートの読み込み」シートの B2（名前「フォルダ」）に、休暇申請シートを置いた OneDrive の同期フォルダの場所を入れると、開いたときに承認済みの申請を読み込む。
- 年次休暇・月別取得時間のシートは「休暇等」シート（1人1年で1行）にまとめた。列：A 出勤用ID, B 年, C 本年分, D 繰越分（活用開始時）, E 採用日, F 退職日, G・H 本年使用の調整（導入前の使用もここ）, I〜O 自動（本年分・繰越分・合計・本年使用（休暇申請シート）・本年使用（合計）・残り・翌年繰越）, P〜AA 病気休暇 1〜12月, AB〜AM 看護休暇 1〜12月（休暇申請シートから）, AN 備考。
- 年次休暇の本年使用（計算用 O 列）＝ 休暇等の G・H（調整の手入力）＋ 年休_自動（計算用 T 列）。計算用 U・V 列は月別_自動の病気休暇・看護休暇の行番号。
- 出勤簿の取得時間 ＝ 月別_自動（休暇申請シートだけ。手入力の調整はない）。出勤簿の日付の表の 年次休暇〜職専免（時間）の欄は日別_自動から表示する（隠し列 AD がその日の行番号）。
- 読み込んだ表は行数が変わるので、これを指す式は列全体（`$A:$A`）と行番号で書き、3行目の行数（`=COUNTA(表名[キー])`）の範囲だけを探す。固定の範囲（`A6:A20005`）で書くと、表が伸びたときに Excel が範囲をずらしてしまう。
