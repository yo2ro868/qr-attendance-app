# テレワーク予定表

所属長が、配属の職員のテレワークの予定を管理者に知らせるための Excel です。承認はありません（職員から所属長への利用の申し出は口頭やメール）。
所属に1つの `テレワーク予定表　所属名.xlsx`（全角スペース区切り）を管理者の OneDrive に置き、所属長にだけ「特定のユーザー」で共有します。
出勤・休暇管理データ（tools/matching_excel）が、開いたとき（または［申請を取り込む］）にフォルダごと Power Query で読み、
出勤簿の出勤欄に「テレ」（QR の出勤登録もあれば「○テレ」）、時間のテレワークは備考に時刻を出します。全員の予定と注意は「テレワーク一覧」シートで見ます。

## ひな形の作り方

```
python tools\telework\make_form.py テレワーク予定表（ひな形）.xlsx
```

引き渡し一式（`python tools\leave_sheet\make_package.py`）にも、ひな形と `手順書（テレワーク）.html` が入ります。

## 予定表の作り

- 「予定」シートの表「予定」（5行目が見出し、500行分を用意。シートは保護、所属長の入力欄だけ保護なし）。
- 列：出勤用ID・氏名（確認用。システムは使わない）・日付・区分（終日／時間）・開始時刻・終了時刻・時間（自動）・備考・確認（自動）。
- 時間は開始時刻・終了時刻から12:00〜13:00の休憩を除いて計算（出勤・休暇管理データ 側でも同じ計算をする。ファイルの式の値は使わない）。
- 日付は土日・祝日・年末年始を入力規則で止め、すり抜けたら赤。祝日は非表示（veryHidden）の「管理」シート（matching_excel/holidays.py から）。
- 足りない欄・誤り（区分なし、時間で時刻なし、終日で時刻あり、終了が開始より前、同じ ID・同じ日の重複）は条件付き書式で赤くし、「確認」の列に理由を出す（Excel Online でも動くよう VBA は使わない）。

## 出勤・休暇管理データ での読み込み

| ファイル | 内容 |
|---|---|
| `queries\テレワーク予定表.pq` | 名前「テレワークフォルダ」（テレワーク一覧シート B2）のフォルダの直下の `テレワーク予定表　*.xlsx` を、予定1件1行で読む（接続のみ）。所属はファイル名から。読めないファイルは理由の1行にする |
| `../matching_excel/queries/テレワーク一覧.pq` | 全員の予定と注意（名簿にない ID、土日祝、区分・時刻の誤り、重複、同じ日の承認済みの休暇）。「テレワーク一覧」シートに出す |
| `../matching_excel/queries/テレワーク_日別.pq` | 「出勤用ID|日付」ごとの 表示（テレ）と 備考（時間のテレワークの時刻）。「休暇申請シートの読み込み」シートの AD 列から。出勤簿の隠し列 AA がその行番号 |

表の名前（予定）と見出しは `queries\テレワーク予定表.pq` が参照するので、変えるときはそろえてください。
FastCombine は使わないので、データを読むステップ（設定の値とファイル）は1つにまとめ、他のクエリを参照しない（休暇申請シートと同じ）。
