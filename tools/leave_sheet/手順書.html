休暇申請用紙 手順書（Excel ＋ OneDrive）

職員ごとに1つの Excel の申請用紙を、管理者の OneDrive に置き、本人と所属長だけに共有して使う仕組みです。 本人が申請を書き、所属長が承認欄に入力します。承認済みの申請は、照合用Excel を開いたときに自動で読み込まれ、年次休暇の本年使用・出勤簿の取得時間・出勤簿の日ごとの欄に反映されます。 Power Automate・Forms・共有フォルダは使いません。

本人 ── 自分の申請用紙（Excel の Web 版）に書く ──▶ 所属長に一声かける（Notes・口頭）
所属長 ── 同じ申請用紙の承認欄に「承認」「却下」を入れる
本人 ── 申請用紙の上で、残日数・承認待ちを確かめる（自動計算）
管理者 ── 申請用紙の作成（マクロ）で、職員名簿の全員分の申請用紙を作る ──▶ 本人と所属長に共有
管理者 ── 照合用Excel を開く ──▶ 承認済みの申請が年次休暇・出勤簿に自動で入る

申請用紙の色分け

本人が入力 所属長が入力 管理者が入力 自動（計算式）

  • 基本（管理者）：出勤用ID・氏名・所属長・年・年次休暇の持ち日数・導入前の使用。シートの保護で、本人・所属長は書き換えられません。
  • 年次休暇の残り（自動）：持ち日数・使用済み（承認済み）・承認待ち・残り、病気休暇と看護休暇の取得時間（その年・承認済み）。1日＝7時間45分。
  • 申請（1件1行、300行まで）：本人が 申請日〜事由、所属長が 承認・承認日・コメント を入力。「確認」の欄に、15分単位になっていない・月をまたいでいる、などの注意が自動で出ます。

2. 事前確認

  1. 特定の人への共有：OneDrive で適当なファイルを右クリック →［共有］→ 共有の設定（歯車や「リンクの設定」）で「特定のユーザー」を選べるか確かめます。組織の人を1人指定し、その人がリンクから開けるかも確かめます。
  2. OneDrive の同期：管理者のパソコンのエクスプローラーの左側に「OneDrive - （組織名）」があり、Web で作ったファイルが見えるか確かめます。
  3. デスクトップ版の Excel：管理者のパソコンで Excel を起動でき、［データ］タブに［データの取得］があるか確かめます。
「特定のユーザー」を選べない場合は、組織の設定で共有が制限されています。情報システム担当に確認してください。

3. 申請用紙を置くフォルダを作る

  1. ブラウザで OneDrive を開き、［＋ 作成またはアップロード］→［フォルダー］で「休暇申請」というフォルダを作ります。
  2. 一式の 休暇申請用紙（ひな形）.xlsx は、このフォルダの外（例：OneDrive の「ドキュメント」）にアップロードしておきます。
「休暇申請」フォルダそのものは共有しないでください。フォルダを共有すると、中の全員分の申請用紙が見えてしまいます。共有は、次の 5 でファイル1つずつ行います。

4. 職員ごとの申請用紙を作る（マクロ）

「申請用紙の作成.xlsm」が、照合用Excel の職員名簿の全員について、ひな形をコピーして 休暇申請_出勤用ID_氏名.xlsx を作ります。 基本の欄には 出勤用ID・氏名・年 と、照合用Excel の年次休暇のその年の合計（持ち日数）が自動で入ります。

はじめに一度だけ（マクロの取り込み）

  1. 一式の 申請用紙の作成.xlsm と 申請用紙の作成.bas を、管理者のパソコンの同じフォルダ（例：ドキュメント）に置きます。OneDrive の「休暇申請」フォルダの中には置かないでください。
  2. 申請用紙の作成.xlsm をデスクトップ版の Excel で開きます。黄色いバーが出たら［編集を有効にする］を押します。
  3. Alt＋F11 を押して VBA の画面を開き、［ファイル］→［ファイルのインポート］で 申請用紙の作成.bas を選びます。左の一覧の「標準モジュール」に LeaveSheetMaker が入れば取り込めています。
  4. VBA の画面を閉じ、上書き保存します。
  5. 次に開いたときに「マクロが無効にされました」と出たら、［コンテンツの有効化］を押します。
「セキュリティ リスク　このファイルのソースが信頼できないため、マクロの実行がブロックされました」と赤いバーが出る場合は、ファイルを右クリック →［プロパティ］→ 下の「許可する」にチェック →［OK］してから開き直します。それでもマクロが使えない場合は、組織の設定でマクロが止められています。情報システム担当に確認してください。

申請用紙を作る

  1. 照合用Excel の職員名簿が最新になっていること、年次休暇シートに職員ごとのその年の行（繰越分・本年分）があることを確かめます（持ち日数はここから読みます）。
  2. 申請用紙の作成.xlsm の「設定」シートに入れます。場所は、エクスプローラーでファイル（フォルダ）を Shift キーを押しながら右クリック →［パスとしてコピー］して貼り付けます。
    欄入れるもの
    B3 照合用Excel のファイル照合用Excel.xlsx の場所
    B4 ひな形のファイル休暇申請用紙（ひな形）.xlsx の場所（OneDrive の「休暇申請」フォルダの外に置いたもの）
    B5 作成先のフォルダOneDrive の「休暇申請」フォルダの場所（例：C:\Users\（ユーザー名）\OneDrive - （組織名）\休暇申請）
    B6 年（西暦）申請用紙の「年」に入れる年
    B7 パスワードひな形のシート保護にパスワードをかけた場合だけ
  3. ［申請用紙を作成］を押します。終わると件数が表示され、「結果」シートに職員ごとの結果が出ます。
  4. 作った申請用紙は OneDrive の同期で自動的にアップロードされます。ブラウザの OneDrive で「休暇申請」フォルダを開き、全員分があることを確かめます。
  5. 申請用紙を1つずつ開き（Excel の Web 版）、［校閲］→［シートの保護の解除］→ 基本の所属長を入れる（導入前の使用があれば入れる）→［シートの保護］で戻します。
  • すでに同じ出勤用ID の申請用紙があるときは作りません（上書きしません）。新しい職員を職員名簿に足したら、もう一度［申請用紙を作成］を押せば、増えた人の分だけ作ります。
  • 持ち日数が空欄になった人は、照合用Excel の年次休暇シートにその年の行がありません。行を足してから、申請用紙の持ち日数を手で入れます。
  • 職員名簿の（例）の行は作りません。
シートの保護は、本人や所属長がうっかり計算式や基本の欄を消さないためのものです。パスワードをかけていないので、［シートの保護の解除］を押せば誰でも外せます。気になる場合は、ひな形にパスワード付きで保護をかけ直し、そのパスワードを申請用紙の作成.xlsm の B7 に入れてください（パスワードは管理者だけが控えておきます）。

5. 本人と所属長に共有する

  1. OneDrive で、その職員の申請用紙を右クリック →［共有］。
  2. 共有の設定（「リンクの設定」や歯車）で「特定のユーザー」を選び、編集可にします。
  3. 宛先に本人と所属長の組織のアカウントを入れます。
  4. Outlook のメールは使えないので、［送信］ではなく［リンクのコピー］でリンクをコピーし、Notes で本人と所属長に送ります（次の 6 の案内文に貼り付けます）。
  5. 共有できたかは、ファイルを右クリック →［アクセス許可の管理］（または［詳細］）で確かめられます。本人と所属長の2人だけになっていることを確かめます。
所属長が同じ職員が何人もいる場合も、共有はファイルごとに行います。所属長は、自分の部下の申請用紙のリンクを人数分受け取ります（ブラウザのお気に入りに入れてもらうと便利です）。

6. 職員・所属長への案内（Notes で送る文の例）

件名：休暇申請用紙のご案内

（氏名）さん

休暇の申請は、次の Excel の申請用紙で行います。この用紙は、ご本人と所属長だけが開けます。
（ここに申請用紙のリンクを貼り付け）

■ 申請のしかた
・リンクを開き（組織のアカウントでサインイン）、「申請」シートの黄色の欄に1件1行で書きます。
・休暇の種類と単位は一覧から選びます。1日単位は 開始日・終了日・日数、時間単位は 開始日・時間（例 2:15）を書きます。
・書いたら、所属長にお知らせください。
・上の「年次休暇の残り」で、残日数と承認待ちを確かめられます。
・承認された行は書き換えないでください。取り消すときは所属長にお知らせください。

■ 所属長の方へ
・青の欄（承認・承認日・コメント）に入力してください。承認欄が空欄の行は「承認待ち」です。

7. 照合用Excel への反映

照合用Excel は、開いたときに「休暇申請」フォルダの申請用紙を読み込み、承認欄が「承認」の申請を次の欄に自動で入れます。手で写す・貼り付ける必要はありません。

照合用Excel の欄入る内容
年次休暇シートの本年使用承認済みの年次休暇（開始日の年）と、申請用紙の「導入前の使用」。N列「本年使用（自動・合計）」で確かめられます。繰越分・翌年繰越もこれで計算されます
出勤簿の上の「取得時間」承認済みの病気休暇・看護休暇を、開始日の月ごとに（1日単位は 1日＝7時間45分）
出勤簿の日付の表年次休暇・病気休暇・特別休暇（種別／時間）・介護休暇・介護時間・職専免（種別／時間）の欄に、その日の申請（1日単位は「1日」、時間単位は「2:15」の形）。看護休暇は特別休暇（種別「子の看護」）に入ります。1日単位で何日かにわたる申請は、土日・祝日・年末年始を除いた日に入ります

はじめに一度だけ

  1. 一式の 照合用Excel.xlsx（申請用紙を読み込む版）に、今お使いの照合用Excel の入力内容（職員名簿・年次休暇・月別取得時間・祝日など）を写します。今お使いのものを置き換える場合は、写し終わってから入れ替えてください。
  2. エクスプローラーで「OneDrive - （組織名）」の中の「休暇申請」フォルダを右クリック →［このデバイス上に常に保持する］。
  3. 照合用Excel を開き、「申請用紙の読み込み」シートの B2 に「休暇申請」フォルダの場所を入れて、上書き保存します。
  4. 開いたときに黄色いバーで「外部データ接続が無効になっています」と出たら［コンテンツの有効化］を押します（毎回出る場合は、照合用Excel を置いているフォルダを Excel の「信頼できる場所」に加えるか、情報システム担当に相談してください）。

ふだんの使い方

  • 照合用Excel を開くたびに、その時点の申請用紙が読み込まれます。開いたまま最新にしたいときは［データ］→［すべて更新］を押します。
  • 「申請用紙の読み込み」シートの3行目に、読み込んだ行数が出ます。0 行のままのときは B2 の場所と、［コンテンツの有効化］を確かめます。
  • 年次休暇シートの D・E 列と月別取得時間シートは「調整」用です。申請用紙に書かれていない使用があるときだけ入れると、申請用紙の分に足されます。普段は空欄にしておきます（申請用紙の分を写すと二重に数えます）。
  • 出勤簿の日ごとの欄は、印刷の前に手で書き換えることもできます（その出勤簿の表示だけが変わり、申請用紙は変わりません）。
  • 年次休暇の本年使用に入るのは、照合用Excel の年次休暇シートにその職員・年の行があるときです。行がない職員は、行を足してください。

休暇集計（申請一覧）

全員の申請を一覧で見たいときは、休暇集計.xlsx を「休暇申請」フォルダの外に置いて開き、「設定」シートの B3 に「休暇申請」フォルダの場所を入れて［データ］→［すべて更新］を押します。状況（承認待ち・承認・却下・取消）や「確認」の注意で絞り込めます。照合用Excel への反映には使いません。

8. 運用

  • 承認後の書き換え：本人は編集できるので、承認済みの行を書き換えることもできてしまいます。気になる行は、申請用紙を右クリック →［バージョン履歴］で、いつ誰が変えたかを確かめ、元に戻せます。
  • 取り消し：所属長が承認欄を「取消」にします（残日数・集計から外れます）。
  • 異動・所属長の交代：申請用紙の［アクセス許可の管理］で、前の所属長の共有を外して新しい所属長を加え、基本の「所属長」を書き換えます。退職した職員の申請用紙は、集計が終わったら「休暇申請」フォルダの外（保管用のフォルダ）に移します。
  • 年が変わるとき（1月）：
    1. 照合用Excel の年次休暇シートに、職員ごとに新しい年の行（本年分など）を足します。前の年の行の翌年繰越が、新しい年の繰越分に自動で入ります。
    2. 各申請用紙の基本の年と持ち日数（照合用Excel の新しい年の「合計」）を新しい年のものにし、導入前の使用は空欄にします。前の年の申請の行はそのまま残しておきます（残日数は「年」の行だけで計算し、照合用Excel も開始日の年で数えます）。
  • 行が足りなくなったとき：申請は1ファイル300行までです。いっぱいになったら、新しい申請用紙を作って共有し直し、古いものは保管用のフォルダに移します。
  • 新しい職員：照合用Excel の職員名簿と年次休暇シートに足してから、申請用紙の作成.xlsm の［申請用紙を作成］を押し（増えた人の分だけ作られます）、5・6 を行います。

9. うまくいかないとき

状態対処
本人・所属長がリンクを開けない共有の宛先が組織のアカウントになっているか、［アクセス許可の管理］で確かめます。組織のアカウントでサインインしてから開いてもらいます
申請用紙で入力できない欄がある保護されている欄（基本・計算式・残日数）は入力できません。黄色・青の欄に入力します
「年次休暇の残り」が出ない、0 のまま基本の「年」と、申請の開始日の年が同じか確かめます
［申請用紙を作成］を押しても何も起きない、マクロのエラーが出る4 の「マクロの取り込み」が済んでいるか、［コンテンツの有効化］を押したかを確かめます。結果シートの D2 に理由が出ていることもあります
照合用Excel に申請が入らない「申請用紙の読み込み」シートの B2 のフォルダの場所、［コンテンツの有効化］、所属長の承認欄が「承認」になっているか、年次休暇シートにその職員・年の行があるかを確かめます
休暇集計で［すべて更新］を押すとエラーになる「設定」シートの B3 のフォルダの場所が正しいか、［コンテンツの有効化］を押したか確かめます
申請一覧に「このファイルを読み取れませんでした」そのファイルの「基本」「申請」の表の名前や見出しが変わっていないか確かめます。分からなければ、ひな形から作り直して申請を写します
ある人の申請が集計に出ないファイル名が「休暇申請_」で始まっているか、「休暇申請」フォルダの中にあるか、同期が終わっているか（エクスプローラーでファイルに緑のチェックが付いているか）を確かめます
