休暇申請用紙 手順書（Excel ＋ OneDrive）

職員ごとに1つの Excel の申請用紙を、管理者の OneDrive に置き、本人と所属長だけに共有して使う仕組みです。 本人が申請を書き、所属長が承認欄に入力します。管理者は「休暇集計」で全員分をまとめ、別途引き渡す照合用Excel に写します。 Power Automate・Forms・共有フォルダは使いません。

本人 ── 自分の申請用紙（Excel の Web 版）に書く ──▶ 所属長に一声かける（Notes・口頭）
所属長 ── 同じ申請用紙の承認欄に「承認」「却下」を入れる
本人 ── 申請用紙の上で、残日数・承認待ちを確かめる（自動計算）
管理者 ── 休暇集計（デスクトップ版 Excel）で［すべて更新］──▶ 照合用Excel に写す・貼り付ける

1. この一式に入っているもの・必要なもの

ファイル内容
手順書.htmlこの手順書
休暇申請用紙（ひな形）.xlsx職員ごとにコピーして使う申請用紙のひな形（「申請」「使い方」シート）
休暇集計.xlsx全員の申請用紙を読み込んで、申請の一覧と、照合用Excel に写す値を作る（管理者だけが使う）
  • 職員・所属長：組織のアカウントで、ブラウザから Excel（Web 版）を使えること
  • 管理者：OneDrive で特定の人だけにファイルを共有できること、管理者のパソコンにデスクトップ版の Excelと OneDrive の同期があること
  • 別途引き渡す照合用Excel（出勤用ID と年次休暇の持ち日数をここから写します）

申請用紙の色分け

本人が入力 所属長が入力 管理者が入力 自動（計算式）

  • 基本（管理者）：出勤用ID・氏名・所属長・年・年次休暇の持ち日数・導入前の使用。シートの保護で、本人・所属長は書き換えられません。
  • 年次休暇の残り（自動）：持ち日数・使用済み（承認済み）・承認待ち・残り、病気休暇と看護休暇の取得時間（その年・承認済み）。1日＝7時間45分。
  • 申請（1件1行、300行まで）：本人が 申請日〜事由、所属長が 承認・承認日・コメント を入力。「確認」の欄に、15分単位になっていない・月をまたいでいる、などの注意が自動で出ます。

2. 事前確認

  1. 特定の人への共有：OneDrive で適当なファイルを右クリック →［共有］→ 共有の設定（歯車や「リンクの設定」）で「特定のユーザー」を選べるか確かめます。組織の人を1人指定し、その人がリンクから開けるかも確かめます。
  2. OneDrive の同期：管理者のパソコンのエクスプローラーの左側に「OneDrive - （組織名）」があり、Web で作ったファイルが見えるか確かめます。
  3. デスクトップ版の Excel：管理者のパソコンで Excel を起動でき、［データ］タブに［データの取得］があるか確かめます。
「特定のユーザー」を選べない場合は、組織の設定で共有が制限されています。情報システム担当に確認してください。

3. 申請用紙を置くフォルダを作る

  1. ブラウザで OneDrive を開き、［＋ 作成またはアップロード］→［フォルダー］で「休暇申請」というフォルダを作ります。
  2. 一式の 休暇申請用紙（ひな形）.xlsx は、このフォルダの外（例：OneDrive の「ドキュメント」）にアップロードしておきます。
「休暇申請」フォルダそのものは共有しないでください。フォルダを共有すると、中の全員分の申請用紙が見えてしまいます。共有は、次の 5 でファイル1つずつ行います。

4. 職員ごとの申請用紙を作る

職員1人ごとに、次をくり返します。

  1. OneDrive で ひな形 を右クリック →［コピー］→ コピー先に「休暇申請」フォルダを選びます。
  2. コピーしたファイルを右クリック →［名前の変更］で 休暇申請_出勤用ID_氏名.xlsx にします（例：休暇申請_1234_山田太郎.xlsx）。
    名前は必ず「休暇申請_」で始めます（集計はこの名前のファイルだけを読みます）。
  3. ファイルを開き（Excel の Web 版）、［校閲］→［シートの保護の解除］を押します（「シートの保護」ボタンを押して解除する画面のこともあります）。
  4. 緑の欄（4行目）に入力します。
    欄入れるもの
    出勤用ID照合用Excel の「職員名簿」と同じ ID
    氏名・所属長本人の氏名、所属長の氏名
    年今の年（西暦。例 2026）
    年次休暇の持ち日数（日）照合用Excel の「年次休暇」シートの、その年の「合計（自動）」の日数（繰越分＋本年分）
    導入前の使用（日）・（時間）この申請用紙を使い始める前に、その年にすでに使った年次休暇。時間は「時間:分」（例 2:15）。なければ空欄
  5. ［校閲］→［シートの保護］で保護を戻します（パスワードは不要）。
シートの保護は、本人や所属長がうっかり計算式や基本の欄を消さないためのものです。パスワードをかけていないので、［シートの保護の解除］を押せば誰でも外せます。気になる場合は、保護するときにパスワードを付けてください（パスワードは管理者だけが控えておきます）。

5. 本人と所属長に共有する

  1. OneDrive で、その職員の申請用紙を右クリック →［共有］。
  2. 共有の設定（「リンクの設定」や歯車）で「特定のユーザー」を選び、編集可にします。
  3. 宛先に本人と所属長の組織のアカウントを入れます。
  4. Outlook のメールは使えないので、［送信］ではなく［リンクのコピー］でリンクをコピーし、Notes で本人と所属長に送ります（次の 6 の案内文に貼り付けます）。
  5. 共有できたかは、ファイルを右クリック →［アクセス許可の管理］（または［詳細］）で確かめられます。本人と所属長の2人だけになっていることを確かめます。
所属長が同じ職員が何人もいる場合も、共有はファイルごとに行います。所属長は、自分の部下の申請用紙のリンクを人数分受け取ります（ブラウザのお気に入りに入れてもらうと便利です）。

6. 職員・所属長への案内（Notes で送る文の例）

件名：休暇申請用紙のご案内

（氏名）さん

休暇の申請は、次の Excel の申請用紙で行います。この用紙は、ご本人と所属長だけが開けます。
（ここに申請用紙のリンクを貼り付け）

■ 申請のしかた
・リンクを開き（組織のアカウントでサインイン）、「申請」シートの黄色の欄に1件1行で書きます。
・休暇の種類と単位は一覧から選びます。1日単位は 開始日・終了日・日数、時間単位は 開始日・時間（例 2:15）を書きます。
・書いたら、所属長にお知らせください。
・上の「年次休暇の残り」で、残日数と承認待ちを確かめられます。
・承認された行は書き換えないでください。取り消すときは所属長にお知らせください。

■ 所属長の方へ
・青の欄（承認・承認日・コメント）に入力してください。承認欄が空欄の行は「承認待ち」です。

7. 集計して照合用Excel に反映する（管理者のパソコン）

はじめに一度だけ

  1. エクスプローラーで「OneDrive - （組織名）」の中の「休暇申請」フォルダを右クリック →［このデバイス上に常に保持する］。
  2. 一式の 休暇集計.xlsx を、「休暇申請」フォルダの外（例：パソコンのドキュメント）に置き、デスクトップ版の Excel で開きます。
  3. 黄色いバーに「セキュリティの警告　外部データ接続が無効になっています」と出たら、［コンテンツの有効化］を押します。
  4. 「設定」シートの B3 に「休暇申請」フォルダの場所を入れます。エクスプローラーでフォルダを開き、上のアドレス欄をクリックすると出る文字（例：C:\Users\（ユーザー名）\OneDrive - （組織名）\休暇申請）をコピーして貼り付けます。
  5. B4 に集計する年を入れて、上書き保存します。

集計するたびに

  1. 休暇集計.xlsx を開き、［データ］→［すべて更新］を押します（全員の申請用紙を読み直します。人数によって数十秒かかります）。
  2. 申請一覧シート：全員の申請が出ます。見出しの ▼ で、状況（承認待ち・承認・却下・取消）や「確認」の注意を絞り込めます。読み取れなかった申請用紙は先頭に出ます。
  3. 照合用_年次休暇シート：本年使用（日）・本年使用（時間）を、照合用Excel の「年次休暇」シートの同じ出勤用ID・年の行に写します（承認済みの年次休暇と、導入前の使用の合計です）。
  4. 照合用_月別取得時間シート：見出しを除いてコピーし、照合用Excel の「月別取得時間」シートに値で貼り付けます（同じ ID・年・区分の古い行は消します）。病気休暇・看護休暇の1日単位は、1日＝7時間45分として時間にしています。
集計は、承認欄が「承認」の行だけを数えます。日付は開始日で、その年・その月に入れます。

8. 運用

  • 承認後の書き換え：本人は編集できるので、承認済みの行を書き換えることもできてしまいます。気になる行は、申請用紙を右クリック →［バージョン履歴］で、いつ誰が変えたかを確かめ、元に戻せます。
  • 取り消し：所属長が承認欄を「取消」にします（残日数・集計から外れます）。
  • 異動・所属長の交代：申請用紙の［アクセス許可の管理］で、前の所属長の共有を外して新しい所属長を加え、基本の「所属長」を書き換えます。退職した職員の申請用紙は、集計が終わったら「休暇申請」フォルダの外（保管用のフォルダ）に移します。
  • 年が変わるとき（1月）：
    1. 前の年の集計を終え、照合用Excel に反映します（B4 を前の年にして［すべて更新］）。
    2. 照合用Excel で新しい年の「合計」（繰越分＋本年分）が出たら、各申請用紙の基本の年と持ち日数を新しい年のものにし、導入前の使用は空欄にします。前の年の申請の行はそのまま残しておきます（残日数は「年」の行だけで計算します）。
  • 行が足りなくなったとき：申請は1ファイル300行までです。いっぱいになったら、新しい申請用紙を作って共有し直し、古いものは保管用のフォルダに移します。
  • 新しい職員：4・5・6 を行います。

9. うまくいかないとき

状態対処
本人・所属長がリンクを開けない共有の宛先が組織のアカウントになっているか、［アクセス許可の管理］で確かめます。組織のアカウントでサインインしてから開いてもらいます
申請用紙で入力できない欄がある保護されている欄（基本・計算式・残日数）は入力できません。黄色・青の欄に入力します
「年次休暇の残り」が出ない、0 のまま基本の「年」と、申請の開始日の年が同じか確かめます
集計で［すべて更新］を押すとエラーになる「設定」シートの B3 のフォルダの場所が正しいか、［コンテンツの有効化］を押したか確かめます
申請一覧に「このファイルを読み取れませんでした」そのファイルの「基本」「申請」の表の名前や見出しが変わっていないか確かめます。分からなければ、ひな形から作り直して申請を写します
ある人の申請が集計に出ないファイル名が「休暇申請_」で始まっているか、「休暇申請」フォルダの中にあるか、同期が終わっているか（エクスプローラーでファイルに緑のチェックが付いているか）を確かめます
