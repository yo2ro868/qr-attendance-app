# 休暇申請用紙（Excel ＋ OneDrive）

職員ごとに1つの Excel の申請用紙を管理者の OneDrive に置き、本人と所属長だけに共有して、休暇の申請・承認を行う仕組みです。
組織では Power Automate・Forms が使えず（Forms はいずれ使えるようになる見込み）、共有フォルダは第三者に見えるので使いません。
管理者は「休暇集計」（デスクトップ版 Excel の Power Query）で全員分を読み込み、照合用Excel の様式（「年次休暇」「月別取得時間」シートの列の並び）で集計します。

**構築と運用は別のPCで行います。** このフォルダはそのPCに引き渡す一式を作るためのものです。

## 引き渡し一式の作り方

プロジェクトのフォルダで次を実行すると、プロジェクト直下に `休暇申請用紙一式\` と `休暇申請用紙一式.zip` ができます（どちらも Git には含めません）。
休暇集計.xlsx に Power Query を入れるため、このPCに Excel が必要です。

```
python tools\leave_sheet\make_package.py
```

| 一式のファイル | 内容 |
|---|---|
| `手順書.html` | 別のPCでの準備・共有・集計・運用の手順 |
| `休暇申請用紙（ひな形）.xlsx` | 職員ごとにコピーする申請用紙 |
| `休暇集計.xlsx` | 全員の申請用紙を読み込む集計ブック（Power Query 入り） |

## このフォルダのファイル

| ファイル | 内容 |
|---|---|
| `make_form.py` | 申請用紙のひな形を作る（表「基本」「申請」、ドロップダウン、残日数と確認の計算式、シートの保護） |
| `make_summary.py` | 集計ブックの土台（設定シート、名前「フォルダ」「集計年」、出力先のシート）を作る |
| `build_summary.ps1` | Excel で `queries\*.pq` を集計ブックに入れて表を作る（`-Folder` を付けると、そのフォルダを読んだ状態で保存して確かめられる） |
| `queries\申請用紙.pq` | フォルダの `休暇申請_*.xlsx` を1ファイル1行で読む（接続のみ） |
| `queries\申請データ.pq` | 全員の申請を1件1行にする。取得時間は分（1日＝465分） |
| `queries\申請一覧.pq` ほか2つ | シートに出す表（申請一覧・照合用_年次休暇・照合用_月別取得時間） |
| `make_package.py` | 引き渡し一式を作る |

申請用紙の表の名前（基本・申請）と見出し、休暇の種類の文字は、`queries\*.pq` が参照しています。変えるときは両方そろえてください。

## 注意

- Power Query の M では、レコードの中で同じ名前のフィールドがローカル変数より優先される。`[分 = 日数 * 465]` の `日数` はフィールドを指すので、ローカル変数はフィールドと違う名前にする（`日数の値` など）。
- 集計ブックは、設定シートの値（フォルダ）と申請用紙を組み合わせるので、`Queries.FastCombine`（プライバシー レベルを無視）をオンにしている。
- 古い Excel でも動くように、M では `??` 演算子を使わない。
