# 休暇申請（Microsoft Forms ＋ 休暇申請シート）

**2026-11 から Microsoft Forms が使えるようになったので、申請は Forms（休暇申請フォーム・休暇承認フォーム）を主にし、職員ごとの休暇申請シートもあわせて使えるようにしています。** Power Automate は使えないので、Forms の回答は「Excel 用 Forms」で OneDrive の Excel に自動でためて、出勤・休暇管理データ が Power Query で読みます（`tools/matching_excel/queries/Forms申請.pq`・`Forms承認.pq`）。承認は、所属長が休暇承認フォームに 出勤用ID・開始日・休暇の種類・結果 を回答し、そのキーで申請と突き合わせます（Forms は回答者に申請番号を見せられないため）。手順は `手順書（Forms）.html`。

以下は休暇申請シートのしくみです。

職員ごとに1つの Excel の休暇申請シートを管理者の OneDrive に置き、本人と所属長だけに共有して、休暇の申請・承認を行う仕組みです。
組織では Power Automate・Forms が使えず（Forms はいずれ使えるようになる見込み）、共有フォルダは第三者に見えるので使いません。
承認済みの申請は、出勤・休暇管理データ（tools/matching_excel）が開いたときに Power Query で直接読み込み、年次休暇の本年使用・出勤簿の取得時間・出勤簿の日ごとの欄に反映します。
職員ごとの休暇申請シートは、管理者がマクロ（休暇申請シートの作成.xlsm）で出勤・休暇管理データ の職員名簿からまとめて作ります。
休暇申請シートには管理者が入力する欄はありません。出勤用ID・氏名はファイル名から、年・合計・本年使用の調整は出勤・休暇管理データ の「休暇等」シートで全職員分を管理し、
マクロの［休暇申請シートを更新］が各休暇申請シートの非表示（veryHidden）の「管理」シートに書き込みます（休暇申請シートから出勤・休暇管理データ を参照すると、本人は出勤・休暇管理データ を開けないので値が取れないため、管理者側から書き込む）。

**構築と運用は別のPCで行います。** このフォルダはそのPCに引き渡す一式を作るためのものです。

## 引き渡し一式の作り方

プロジェクトのフォルダで次を実行すると、プロジェクト直下に `休暇申請一式\` と `休暇申請一式.zip` ができます（どちらも Git には含めません）。
休暇集計.xlsx・出勤・休暇管理データ.xlsm に Power Query を入れるため、このPCに Excel が必要です。

```
python tools\leave_sheet\make_package.py
```

| 一式のファイル | 内容 |
|---|---|
| `手順書（Forms）.html` | Forms の2つのフォームの作り方・出勤・休暇管理データ の設定・運用 |
| `手順書.html` | 休暇申請シートの準備・共有・集計・運用の手順 |
| `休暇申請シート（ひな形）.xlsx` | 職員ごとにコピーする休暇申請シート |
| `休暇申請シートの作成.xlsm` と `休暇申請シートの作成.bas` | 職員名簿から休暇申請シートをまとめて作るマクロ（.bas は使う人が一度だけ取り込む） |
| `出勤・休暇管理データ.xlsm` と `出勤・休暇管理データのマクロ.bas` | 休暇申請シート・Forms を読み込む版の出勤・休暇管理データ（空の様式。tools/matching_excel/build.ps1 で作る）と、［申請を取り込む］のマクロ（使う人が一度だけ取り込む） |
| `休暇集計.xlsx` | 全員の申請の一覧（Power Query 入り） |

## このフォルダのファイル

| ファイル | 内容 |
|---|---|
| `make_form.py` | 休暇申請シートのひな形を作る（表「申請」、非表示の「管理」シート、ドロップダウン、残日数と確認の計算式、シートの保護） |
| `macro/休暇申請シートの作成.bas` | 休暇申請シートを職員分作る・全員分を更新するマクロ（VBA）。出勤・休暇管理データ の職員名簿、計算用シートの年次休暇の合計（分）、休暇等シートの調整を読み、休暇申請シートの「管理」シートに書く |
| `build_macro.ps1` | 休暇申請シートの作成.xlsm（設定・結果シートと3つのボタン）と、Shift_JIS の .bas を作る。VBA はスクリプトから入れられない（Excel の「VBA プロジェクト オブジェクト モデルへのアクセスを信頼する」がオフ）ので、使う人が取り込む |
| `make_summary.py` | 集計ブックの土台（設定シート、名前「フォルダ」、出力先のシート）を作る |
| `build_summary.ps1` | Excel で `queries\*.pq` を集計ブックに入れて表を作る（`-Folder` を付けると、そのフォルダを読んだ状態で保存して確かめられる） |
| `queries\休暇申請シート.pq` | フォルダの `休暇申請シート　*.xlsx` を1ファイル1行で読む（接続のみ）。出勤用ID・氏名はファイル名から。超過勤務等命令簿の月のシートの表（超勤日別*）は「超勤」の列に入る（tools/overtime）。ファイルは1回だけ読むように結果を Table.Buffer する（使う側がたどるたびに読み直すと、月のシートが入ってファイルが大きくなった分とても遅くなるため） |
| `queries\申請データ.pq` | 全員の申請を1件1行にする。取得時間は分（1日＝465分） |
| `queries\申請一覧.pq` | 休暇集計の「申請一覧」シートに出す表 |
| `make_package.py` | 引き渡し一式を作る |

休暇申請シートの表の名前（申請）と見出し、休暇の種類の文字は、`queries\*.pq` と `tools/matching_excel/queries\*.pq` が参照しています。変えるときはそろえてください。
`queries\休暇申請シート.pq`・`申請データ.pq` は出勤・休暇管理データ でも使います（`tools/matching_excel/add_queries.ps1` が読み込む）。

単位が1つに決まる休暇は `make_form.py` の `UNIT_TIME_ONLY`・`UNIT_DAY_ONLY` に足します（管理シートの G・H 列に入り、隠し列 R で判定。単位の欄の既定の式と一覧の絞り込みに使います）。今は 介護時間・育児時間 が時間・分単位だけ、日単位だけは該当なし（資料の単位の記載による）。

ひな形には、超過勤務等命令簿の非表示（veryHidden）の「超勤ひな形」シートも入ります（`tools/overtime/add_overtime_sheet.ps1` が、いま使っている命令簿の Excel から写す。名前「休日」「振替」は管理シートの D:E 列・X 列）。
マクロの［超過勤務の月を追加］が、設定シートの B7 の月の「超勤 R8.12」などのシートを全員の休暇申請シートに作ります（tools/overtime/README.md）。

様式を変えたら `make_form.py` の `FORM_VERSION` を変えます。マクロの［休暇申請シートを更新］が古い様式を結果シートで知らせ、［様式を移行］が申請の行を見出しの名前で新しい様式へ写します（式の入ったセルは写さない）。

開始日・終了日に土日祝を入れてよい休暇を増やすときは、`make_form.py` の `OFF_DAY_OK` に休暇の種類か種別の文字を足します（管理シートの F 列に入り、隠し列 Q で判定します。今は例外なし）。日数の計算は例外の休暇でも土日祝を除くので、暦どおりに数える休暇を足すときは日数の式も見直してください。

マクロ（VBA）はこのPCでは動かして確かめていません（スクリプトから取り込めないため）。直したら、Excel で取り込んで動かしてください。

## 注意

- Power Query の M では、レコードの中で同じ名前のフィールドがローカル変数より優先される。`[分 = 日数 * 465]` の `日数` はフィールドを指すので、ローカル変数はフィールドと違う名前にする（`日数の値` など）。
- `Queries.FastCombine`（プライバシー レベルを無視）は使わない。作ったPC以外には引き継がれず、ほかのPCで「データの組み合わせを再構築してください」で止まるため。データを読むステップ（設定の値とファイル）は他のクエリやステップを参照せず1つにまとめ、他のクエリを参照する側ではデータを読まない。確かめるときは `FastCombine = $false` で読み直す。
- 古い Excel でも動くように、M では `??` 演算子を使わない。
