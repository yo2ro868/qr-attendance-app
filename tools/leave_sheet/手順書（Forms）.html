Forms 休暇申請 手順書（Microsoft Forms ＋ 照合用Excel）

職員は 休暇申請フォーム で休暇を申請し、所属長は 休暇承認フォーム で承認・却下します。 2つのフォームの回答は、Forms の機能で管理者の OneDrive の Excel に自動でたまります。 照合用Excel を開くと、その Excel を読み込み、承認済みの申請を休暇等シート・出勤簿に反映します。Power Automate は使いません。

本人   ── 休暇申請フォームに回答 ──▶ 所属長に「出勤用ID・開始日・休暇の種類」を伝える（Notes・口頭）
所属長 ── 休暇承認フォームに回答（出勤用ID・開始日・休暇の種類・承認／却下／取消）
（Forms）── 2つの回答が、管理者の OneDrive の Excel に自動でたまる
管理者 ── 照合用Excel を開く ──▶ 申請と承認を突き合わせ、承認済みだけを休暇等・出勤簿に反映
                              └▶ 申請一覧シートで、全員の申請・承認待ち・注意を確かめる

これまでの休暇申請用紙（職員ごとの Excel）も、あわせて使えます。照合用Excel は両方を読み込みます（申請用紙の手順は「手順書.html」）。

1. 必要なもの・事前確認

  • Microsoft Forms と、Excel（Web 版）・OneDrive
  • 管理者のパソコンに、デスクトップ版の Excel と OneDrive の同期（照合用Excel が回答の Excel を読むため）
  • 照合用Excel（休暇等シート・申請一覧シートの版）

回答が Excel にたまるかの確認（数分）

  1. ブラウザで OneDrive を開き、［＋ 作成またはアップロード］→［Excel 用 Forms］（または［Forms for Excel］）を選び、名前を「確認用」にして作ります。メニューにないときは、OneDrive で新しい Excel ブックを作り、Excel（Web 版）の［挿入］→［Forms］→［新しいフォーム］で作ります。
  2. 質問を1つ作り、［回答を収集］からリンクを開いて自分で回答します。
  3. OneDrive の「確認用.xlsx」を開き、回答の行が増えていることを確かめます（数分かかることがあります）。
  4. エクスプローラーの「OneDrive - （組織名）」にも「確認用.xlsx」があることを確かめます（同期）。
この方法で作ったフォームは、回答がその Excel に自動で追記され続けます。Forms の画面の［Excel で開く］で毎回ダウンロードする方法では自動でたまらないので、必ず上の方法で作ってください。確認が終わったら「確認用」は削除してかまいません。

2. 休暇申請フォームを作る

  1. OneDrive に「休暇申請」などのフォルダを作り、その中で［＋ 作成またはアップロード］→［Excel 用 Forms］を選び、名前を 休暇申請フォーム にします（同じ名前の Excel ができ、回答はここにたまります）。
  2. ［設定］で：回答できるユーザー＝組織内のユーザーのみ、名前を記録をオン（回答者のメールアドレスで本人を見分けます）、1人につき1つの回答＝オフ。
  3. 次の質問を作ります。質問の文（太字）は、回答の Excel の見出しになり、照合用Excel がその名前で読み取るので、このとおりに入れてください。選択肢の文字もこのとおりにします（かっこは全角）。

質問の文形式必須選択肢・設定

分岐（質問の［…］→［分岐を追加］）：特別休暇（看護休暇以外）→ セクション2、職務専念義務の免除 → セクション3、それ以外 → セクション4。

3. 休暇承認フォームを作る

  1. 同じフォルダで［Excel 用 Forms］を選び、名前を 休暇承認フォーム にします。
  2. ［設定］で：回答できるユーザー＝組織内の特定のユーザー（所属長の方々を指定）または組織内のユーザーのみ、名前を記録をオン、1人につき1つの回答＝オフ。
  3. 次の質問を作ります（質問の文はこのとおりに）。
質問の文形式必須選択肢・設定
申請者の出勤用IDテキスト○本人から伝えられた出勤用ID
休暇の開始日日付○時間単位の申請は取得日
休暇の種類選択肢○休暇申請フォームの「休暇の種類」と同じ8つ
結果選択肢○承認／却下／取消
コメントテキスト
  • 照合用Excel は、出勤用ID・開始日・休暇の種類が同じ申請に、この回答を当てはめます。同じ申請に何度か回答したときは、いちばん新しい回答が使われます（承認を取り消すときは「取消」で回答し直します）。
  • 同じ人が同じ日に同じ種類で2件申請した場合（時間単位を2回など）は、1回の承認で両方が承認になります。

4. 照合用Excel の設定

  1. 職員名簿シートの C列「メールアドレス」に、職員ごとの組織のアカウント（Forms に回答するときのアドレス）を入れます。休暇申請フォームの回答は、このメールアドレスで職員を見分けます。
  2. エクスプローラーで「OneDrive - （組織名）」の中の、2つのフォームの Excel（休暇申請フォーム.xlsx・休暇承認フォーム.xlsx）を右クリック →［このデバイス上に常に保持する］。
  3. 照合用Excel の「申請用紙の読み込み」シートに場所を入れます。ファイルを Shift キーを押しながら右クリック →［パスとしてコピー］して貼り付けます。
    欄入れるもの
    B2 申請用紙のフォルダ休暇申請用紙も使うときだけ（使わなければ空欄）
    B3 Forms 申請の回答休暇申請フォーム.xlsx の場所
    B4 Forms 承認の回答休暇承認フォーム.xlsx の場所
  4. 上書き保存して開き直し、黄色いバーが出たら［コンテンツの有効化］を押します。
  5. 自分で休暇申請フォームと休暇承認フォームに試しに回答し、照合用Excel を開き直して（または［データ］→［すべて更新］）、申請一覧シートに「Forms」の行が出て、状況が「承認」になることを確かめます。
試しの回答は、2つのフォームの Excel の行を削除すれば消えます（Forms の［回答］タブの［すべての回答を削除］でも消せます）。

5. 職員・所属長への案内（Notes で送る文の例）

件名：休暇の申請は Forms でお願いします

■ 職員の方
・休暇の申請は、次のフォームで行います。（休暇申請フォームのリンク）
・申請したら、所属長に「出勤用ID・休暇の開始日（時間単位は取得日）・休暇の種類」を伝えてください。
  例：出勤用ID 1234、11月12日、病気休暇
・取り消すときも所属長に伝えてください。

■ 所属長の方
・職員から申請を伝えられたら、次のフォームで承認・却下してください。（休暇承認フォームのリンク）
・出勤用ID・開始日・休暇の種類は、職員から伝えられたとおりに入れてください（違うと承認が届きません）。
・承認を取り消すときは、同じ内容で「取消」を選んで回答してください。

6. 運用

  • 照合用Excelを開くたびに、2つのフォームの回答（と申請用紙）が読み込まれます。申請一覧シートで、全員の申請・状況（承認待ち・承認・却下・取消）・注意（15分単位でない、月をまたいでいる、職員名簿にないメールアドレス、など）を確かめられます。
  • 申請一覧の先頭に「承認フォームの回答に合う Forms の申請がありません」と出たら、所属長の入れた出勤用ID・開始日・休暇の種類が申請と違っています。所属長に正しい内容で回答し直してもらいます（古い回答はそのままでかまいません）。
  • 休暇等シート・出勤簿に入るのは承認済みの申請だけです。承認待ち・却下・取消は入りません。
  • 残日数：Forms だけでは、職員が自分の残日数を見る手段はありません。休暇申請用紙も使っている職員は、申請用紙の作成.xlsm の［申請用紙を更新］を押すと、Forms で承認された年次休暇も申請用紙の「年次休暇の残り」に入ります。
  • 申請の直し：職員が申請を間違えたときは、所属長が「却下」で回答し、職員に正しい内容で申請し直してもらいます。
  • 新しい職員：照合用Excel の職員名簿（メールアドレスも）と休暇等シートに足します。

7. うまくいかないとき

状態対処
申請一覧に Forms の行が出ない「申請用紙の読み込み」シートの B3 の場所、［コンテンツの有効化］、フォームの Excel が同期されているか（エクスプローラーで緑のチェック）を確かめます
Forms の行は出るが、休暇の種類や日付が空欄フォームの Excel の1行目の見出しが、2・3 の「質問の文」と同じか確かめます（違っていたら、フォームの質問の文を直します）
「職員名簿にメールアドレス（…）がありません」照合用Excel の職員名簿の C列に、そのアドレスを入れます（大文字・小文字は区別しません）
承認したのに「承認待ち」のまま承認フォームの 出勤用ID・開始日・休暇の種類 が申請と同じか、申請一覧の先頭の注意を確かめます
回答の Excel に回答が増えないフォームを［Excel 用 Forms］で作ったか確かめます（1 の確認）。Forms の画面からダウンロードした Excel は自動で増えません
