# フレックスタイム制の申告・割振り

休暇申請シート（tools/leave_sheet）に、フレックスタイム制の申告・割振りのシートを入れます。本人が申告し、所属長が単位期間（4週間）ごとに承認（割振り）し、管理者は 出勤・休暇管理データ で承認済みの単位期間を取り込んで、出勤簿の備考と照合に使います。
全員の休暇申請シートに入ります（使わない人は申告年月日を入れないので、管理者側には出ません）。

| シート | 作るもの | 内容 |
|---|---|---|
| フレックス申告 | `flex_sheets.py`（make_form.py から） | 本人が入力。12〜403 行目が始期から392日（4週間×14）。勤務・休憩は時と分を別の欄（既定 9:00〜17:45・休憩 12:00〜13:00 は式。消すと空欄になる）。右に単位期間の表（合計・申告年月日・状態） |
| フレックス割振り | 同上 | 申告を写す（書き換えられない）。右の単位期間の表に所属長の承認・割振年月日 |
| フレックス表（veryHidden） | 同上 | Power Query が読む表「フレックス日別」（1日1行、時刻・時間は分）と「フレックス期間」（状態の判定もここ） |
| 申告・割振り簿 | `add_flex_book.ps1` | 総務課の様式（プロジェクト直下 `申告・割振り簿（原本）.xlsx`。保護を外したもの。Git 外）のシートを写し、申告の欄（Z〜AS）・時間数（AT・AU）・備考・申告年月日・割振年月日・所属・氏名・所属長氏名を式でつなぐ。割振りの欄（D〜Y）は様式の式のまま。単位期間（F5〜I5）だけ書ける |

始期は管理シートの B12（名前 `フレックス始期`、`flex_sheets.FLEX_START`）。どのシートも 12 行目が始期の日で、行の位置をそろえてある。

## 状態（フレックス期間の表）

申告年月日がない → 未申告、合計が 9300 分でない → 合計が155時間ではありません、確認の欄に文がある日がある → 入力に誤りがあります、
承認が「承認」でない → 承認待ち、割振年月日がない → 割振年月日を入れてください、申告年月日 > 割振年月日 → 承認後に申告が変更されました、ほかは 承認済み。

## 出勤・休暇管理データ（tools/matching_excel）

| ファイル | 内容 |
|---|---|
| `../leave_sheet/queries/休暇申請シート.pq` | 表「フレックス日別」「フレックス期間」を フレックス日・フレックス期間 の列に入れる |
| `queries/フレックス_日別.pq` | 今の内容を1日1行（申告年月日のある単位期間がある人だけ）。「フレックスの読み込み」シート |
| `queries/フレックス_確定.pq` | 表 確定_フレックス日別 を読む（データを読むだけのクエリ。他のクエリを参照しない） |
| `queries/フレックス一覧.pq` | 単位期間ごとの状況・取り込み（取り込む／取り込み済み）・注意。「フレックス」シート |
| `queries/フレックス_出勤簿.pq` | 出勤簿の備考（キー 出勤用ID|日付 → 「フ10:00-19:00」「割振なし」）。「休暇申請シートの読み込み」シートの AH 列 |
| `macro/出勤・休暇管理データのマクロ.bas` の `TakeFlexSnapshot` | ［最新を読み込む］の中で、取り込みが「取り込む」の単位期間を「フレックスの日別」（表 確定_フレックス日別）に値で写し、一覧と出勤簿の表を読み直す |

取り込む条件：状態が「承認済み」で、まだ取り込んでいないか、割振年月日が取り込んだときより新しい（承認し直した）。
取り込んだ後に申告が変わったら（日ごとの勤務開始・終了・休憩をつないだ文字で比べる）、一覧の注意に出し、取り込んだ内容を使い続ける。

[様式を移行] は、フレックス申告の D3・H12:Z403・AN12:AN25、フレックス割振りの D3・D4・AO12:AP25 のうち式でないセルを、空欄も含めて新しい様式に写す（`休暇申請シートの作成.bas` の ReadFlexInputs / WriteFlexInputs）。

## まだのこと

- 年度の切り替え（新しい始期にして、前の年度の申告・割振りを残す）。
- マクロ（VBA）はこのPCでは動かして確かめていない（取り込みと移行は同じ手順を PowerShell で動かして確かめた）。
