# フレックスタイム制の申告・割振り

申請・報告シート（tools/leave_sheet）に、フレックスタイム制の申告・割振りのシートを入れます。本人が申告し、所属長が単位期間（4週間）ごとに承認（割振り）し、管理者は 出勤・休暇管理データ で承認済みの単位期間を取り込んで、出勤簿の備考と照合に使います。
全員の申請・報告シートに入ります（使わない人は申告年月日を入れないので、管理者側には出ません）。

| シート | 作るもの | 内容 |
|---|---|---|
| フレックス（単位期間・承認） | `flex_sheets.py`（make_form.py から） | 単位期間ごとに1行の表（8 行目が見出し、9〜22 行目が期間 1〜14）。B 開始日・F 申告年月日（本人）、G 承認・H 割振年月日（所属長）、C 終了日・D 合計・E 155時間との差・I 状態（自動）。上に C3 所属（既定は管理シート B16＝職員名簿の部・課）・C4 氏名・C5 所属長氏名（既定は管理シート B15＝職員名簿の所属長氏名）・C6 異動後の所属長氏名 |
| フレックス（申告の内容） | 同上 | 本人が入力。12〜403 行目が392日（12 行目＝単位期間1の開始日。なければ始期）。上の固定した行の N3〜AA6 に、表示する単位期間（T3。空欄なら今日を含む期間。隠し列 AB3 が番号）の期間・合計・155時間との差・状態 |
| フレックス表（veryHidden） | 同上 | Power Query が読む表「フレックス日別」（1日1行、時刻・時間は分）と「フレックス期間」（状態の判定もここ） |
| 申告・割振り簿 | `add_flex_book.ps1` | 総務課の様式（プロジェクト直下 `申告・割振り簿（原本）.xlsx`。保護を外したもの。Git 外）のシートを写し、申告の欄（Z〜AS）・時間数（AT・AU）・備考・申告年月日・割振年月日・所属・氏名・所属長氏名を式でつなぐ。割振りの欄（D〜Y）は様式の式のまま。単位期間（F5〜I5）だけ書ける。**veryHidden**（本人・所属長には見せない。管理者は 申請・報告シートの作成.xlsm の［申告・割振り簿を見る］＝ShowFlexBook で、読み取り専用で開いて表示） |

備考（Z）の既定は式：その日の承認済みの休暇（休暇申請の表の行番号を隠し列 AI で探す。土日・祝日は土日祝でも取れる休暇だけ）の種別（なければ休暇の種類）と、時間・分単位なら時刻。本人が書き換えると値になる（移行では値だけ写す）。

始期は管理シートの B12（名前 `フレックス始期`、`flex_sheets.FLEX_START`）。日ごとの表の最初の日は フレックス（申告の内容）!B12（単位期間1の開始日、なければ始期）で、割振り・フレックス表・申告・割振り簿（F4〜I4）も同じ日から始まり、行の位置をそろえてある。

## 状態（フレックス期間の表）

開始日がない → 空（使わない）、開始日が表の日の外・前の単位期間と重なる → その旨、申告年月日がない → 未申告、合計が 9300 分でない → 合計が155時間ではありません、確認の欄に文がある日がある → 入力に誤りがあります、
承認が「承認」でない → 承認待ち、割振年月日がない → 割振年月日を入れてください、申告年月日 > 割振年月日 → 承認後に申告が変更されました、ほかは 承認済み。

## 出勤・休暇管理データ（tools/matching_excel）

| ファイル | 内容 |
|---|---|
| `../leave_sheet/queries/休暇申請シート.pq` | 表「フレックス日別」「フレックス期間」を フレックス日・フレックス期間 の列に入れる |
| `queries/フレックス_日別.pq` | 今の内容を1日1行（申告年月日のある単位期間がある人だけ）。「フレックス読み込み」シート |
| `queries/フレックス_確定.pq` | 表 確定_フレックス日別 を読む（データを読むだけのクエリ。他のクエリを参照しない） |
| `queries/フレックス一覧.pq` | 単位期間ごとの状況・取り込み（取り込む／取り込み済み）・注意。「フレックス①承認状況」シート |
| `queries/フレックス_出勤簿.pq` | 出勤簿の備考（キー 出勤用ID|日付 → 「フ10:00-19:00」「割振なし」）。「休暇読み込み」シートの AH 列 |
| `macro/出勤・休暇管理データのマクロ.bas` の `TakeFlexSnapshot` | ［最新を読み込む］の中で、取り込みが「取り込む」の単位期間を「フレックス日別照合」（表 確定_フレックス日別）に値で写し、一覧と出勤簿の表を読み直す |

取り込む条件：状態が「承認済み」で、まだ取り込んでいないか、割振年月日が取り込んだときより新しい（承認し直した）。
取り込んだ後に申告が変わったら（日ごとの勤務開始・終了・休憩をつないだ文字で比べる）、一覧の注意に出し、取り込んだ内容を使い続ける。

[様式を移行] は、フレックス（単位期間・承認） の C3・C5・C6・B9:B22・F9:H22 と フレックス（申告の内容） の H12:Z403 を写す（日ごとの欄は、単位期間1の開始日が変われば同じ日の行にずらす）。2026-11-19 までの様式（フレックス申告の右上の横の表 AK4:AX4・AK7:AX7、フレックス割振り（所属長確認用）の D3・D4・AK8:AX9。さらに前の縦の表 AK12:AK25・AN12:AN25・AO12:AP25）も読んで、新しい形に写す。所属・所属長氏名は、前の様式で空欄なら職員名簿の式のままにする。

## まだのこと

- 年度の切り替え（新しい始期にして、前の年度の申告・割振りを残す）。
- マクロ（VBA）はこのPCでは動かして確かめていない（取り込みと移行は同じ手順を PowerShell で動かして確かめた）。
