# フレックスタイム制の申告・割振り

休暇申請シート（tools/leave_sheet）に、フレックスタイム制の申告・割振りのシートを入れます。本人が申告し、所属長が単位期間（4週間）ごとに承認（割振り）し、管理者は 出勤・休暇管理データ で承認済みの単位期間を取り込んで、出勤簿の備考と照合に使います。
全員の休暇申請シートに入ります（使わない人は申告年月日を入れないので、管理者側には出ません）。

| シート | 作るもの | 内容 |
|---|---|---|
| フレックス申告 | `flex_sheets.py`（make_form.py から） | 本人が入力。12〜403 行目が392日（12 行目＝単位期間1の開始日。なければ始期）。単位期間の表は右上の固定した行（3〜11 行目）に横向き：AJ が見出し、AK〜AX が期間1〜14、3 期間・4 開始日（本人が入力）・5 終了日（＋27日）・6 合計・7 申告年月日（入力）・8〜11 状態。日ごとの期間番号（A）はその日を含む単位期間（重なったら先の期間、どれにも入らなければ空欄で、確認の対象外）。勤務・休憩は時と分を別の欄（既定 9:00〜17:45・休憩 12:00〜13:00 は式。消すと空欄になる）。|
| フレックス割振り（所属長確認用） | 同上 | 申告を写す（書き換えられない）。右上の単位期間の表：3〜7 は申告と同じ、8 承認・9 割振年月日（所属長が入力）・10〜11 状態 |
| フレックス表（veryHidden） | 同上 | Power Query が読む表「フレックス日別」（1日1行、時刻・時間は分）と「フレックス期間」（状態の判定もここ） |
| 申告・割振り簿 | `add_flex_book.ps1` | 総務課の様式（プロジェクト直下 `申告・割振り簿（原本）.xlsx`。保護を外したもの。Git 外）のシートを写し、申告の欄（Z〜AS）・時間数（AT・AU）・備考・申告年月日・割振年月日・所属・氏名・所属長氏名を式でつなぐ。割振りの欄（D〜Y）は様式の式のまま。単位期間（F5〜I5）だけ書ける。**veryHidden**（本人・所属長には見せない。管理者は 休暇申請シートの作成.xlsm の［申告・割振り簿を見る］＝ShowFlexBook で、読み取り専用で開いて表示） |

備考（Z）の既定は式：その日の承認済みの休暇（休暇申請の表の行番号を隠し列 AI で探す。土日・祝日は土日祝でも取れる休暇だけ）の種別（なければ休暇の種類）と、時間・分単位なら時刻。本人が書き換えると値になる（移行では値だけ写す）。

始期は管理シートの B12（名前 `フレックス始期`、`flex_sheets.FLEX_START`）。日ごとの表の最初の日は フレックス申告!B12（単位期間1の開始日、なければ始期）で、割振り・フレックス表・申告・割振り簿（F4〜I4）も同じ日から始まり、行の位置をそろえてある。

## 状態（フレックス期間の表）

開始日がない → 空（使わない）、開始日が表の日の外・前の単位期間と重なる → その旨、申告年月日がない → 未申告、合計が 9300 分でない → 合計が155時間ではありません、確認の欄に文がある日がある → 入力に誤りがあります、
承認が「承認」でない → 承認待ち、割振年月日がない → 割振年月日を入れてください、申告年月日 > 割振年月日 → 承認後に申告が変更されました、ほかは 承認済み。

## 出勤・休暇管理データ（tools/matching_excel）

| ファイル | 内容 |
|---|---|
| `../leave_sheet/queries/休暇申請シート.pq` | 表「フレックス日別」「フレックス期間」を フレックス日・フレックス期間 の列に入れる |
| `queries/フレックス_日別.pq` | 今の内容を1日1行（申告年月日のある単位期間がある人だけ）。「フレックスの読み込み」シート |
| `queries/フレックス_確定.pq` | 表 確定_フレックス日別 を読む（データを読むだけのクエリ。他のクエリを参照しない） |
| `queries/フレックス一覧.pq` | 単位期間ごとの状況・取り込み（取り込む／取り込み済み）・注意。「フレックス」シート |
| `queries/フレックス_出勤簿.pq` | 出勤簿の備考（キー 出勤用ID|日付 → 「フ10:00-19:00」「割振なし」）。「休暇申請シートの読み込み」シートの AH 列 |
| `macro/出勤・休暇管理データのマクロ.bas` の `TakeFlexSnapshot` | ［最新を読み込む］の中で、取り込みが「取り込む」の単位期間を「フレックスの日別」（表 確定_フレックス日別）に値で写し、一覧と出勤簿の表を読み直す |

取り込む条件：状態が「承認済み」で、まだ取り込んでいないか、割振年月日が取り込んだときより新しい（承認し直した）。
取り込んだ後に申告が変わったら（日ごとの勤務開始・終了・休憩をつないだ文字で比べる）、一覧の注意に出し、取り込んだ内容を使い続ける。

[様式を移行] は、フレックス申告の D3・AK4:AX4（開始日）・AK7:AX7（申告年月日）・H12:Z403、フレックス割振り（所属長確認用）（前の名前 フレックス割振り でも読む）の D3・D4・AK8:AX9 のうち式でないセルを、空欄も含めて新しい様式に写す（`休暇申請シートの作成.bas` の ReadFlexInputs / WriteFlexInputs）。2026-11-16 までの縦の表（AJ11 が「期間」：開始日 AK12:AK25・申告年月日 AN12:AN25・承認と割振年月日 AO12:AP25）は横の表に並べ替えて写す（前の様式の開始日が式なら、申告年月日のある行だけ値を写す）。日ごとの表の最初の日が前の様式と違うとき（単位期間1の開始日が始期でない）は、日ごとの欄を同じ日の行にずらして写す。
