# 超過勤務等命令簿

職員が超過勤務の実績をそのつど書き、所属長が1か月分を確認し、管理者が確認済みの月を 出勤・休暇管理データ に写して出勤の記録・休暇と照合します。
承認の流れ（申請→承認）はありません。所属長の確認は、命令簿の最下部の「所属長 確認日及び氏名」に確認日を入れることです。

命令簿は**いま使っている超過勤務等命令簿の Excel をそのまま使います**（支給割合ごとの振り分け・60時間超・手当対象時間の式は、日ごとに手で直したものがあるため作り直さない）。
休暇申請シート（tools/leave_sheet）に、月ごとのシート「超勤 R8.12」などとして入ります。本人と所属長にだけ共有している休暇申請シートなので、共有の手間は増えません。

## しくみ

| 場面 | すること |
|---|---|
| ひな形を作る | `add_overtime_sheet.ps1` が、命令簿の Excel の月のシート（R8.11 など）を休暇申請シートのひな形に写して、非表示（veryHidden）の「超勤ひな形」シートにする |
| 毎月（管理者） | 休暇申請シートの作成.xlsm の［超過勤務の月を追加］：全員の休暇申請シートに、B7 の月のシートを「超勤ひな形」から作る |
| 毎日（職員） | その月のシートの 登庁時刻・退庁時刻（日をまたぐときは 25:00 のように前日の時刻）、振替日・休日の ○、備考 を書く |
| 月末（所属長） | 内容を確かめて、最下部の所属長の確認日（と氏名）を入れる |
| 翌月（管理者） | 出勤・休暇管理データ の「超過勤務」シートの B2 に月を入れて［超過勤務を転記］：確認済みの人の分を写し、「超過勤務の日別」シートの「注意」で照合する |

## 命令簿から写すときに変えるところ（add_overtime_sheet.ps1）

- **W1（年月）**：シート名を読む `CELL("filename")` の式をやめ、マクロが月の1日を書く（`CELL("filename")` は Web の Excel では使えない）。
- **前月の最終日の退庁時刻**：命令簿では1日の欄の式が前月のシート（`'R8.10'!L65`）を指していた。これを同じシートの **BH1** にし、マクロが前月のシートの **BH2**（その月の最終日の退庁時刻。30日の月なら30日の行）を指す式を書く。前月のシートは消さないでください（消すと1日の欄が計算できません）。
- **休日・代休日（H 列）**：祝日・年末年始は自動で ○（名前「休日」＝休暇申請シートの管理シートの祝日 D 列・年末年始 E 列。マクロ［休暇申請シートを更新］が祝日を書き換える）。代休日などは本人が ○ を書く（式の上に書いてよい）。
- 登庁・退庁時刻、振替日の ○、超勤代休、備考、所属部課、所属長の確認日を空にする。登庁・退庁の標準時刻（A・B 列）と休憩時間（I 列）は残す。氏名（R69）は管理シートの氏名。
- 所属部課（L69）と所属長の確認欄（AC69:AE70）、H 列の保護を外し、シートを保護する（命令簿のほかの保護の設定はそのまま）。
- 列の幅：ひな形の標準のフォントが命令簿と違うので、ポイントで同じ幅になるように直す。
- 隠し列 BJ〜 に表「超勤日別」（1日1行。時刻・時間は分、日付は文字）を足す。出勤・休暇管理データ はこの表を Power Query で読む（月のシートを写すと表の名前は 超勤日別2、超勤日別3… になる）。

命令簿の様式を変えたら、新しい命令簿の Excel で引き渡し一式を作り直し（`make_package.py`）、休暇申請シートの作成.xlsm の［様式を移行］で全員分を新しい様式にします。
［様式を移行］は、月のシートの書いた値（本人・所属長の入力欄。式でないセル）を新しい様式の月のシートに写します。

## 作り方

```
python tools\leave_sheet\make_form.py 休暇申請シート（ひな形）.xlsx
powershell -ExecutionPolicy Bypass -File tools\overtime\add_overtime_sheet.ps1 -Template 休暇申請シート（ひな形）.xlsx -Source 超過勤務命令簿.xlsx
```

`-Sheet` を省くと、命令簿の R年.月 の名前のシートのうち、いちばん新しい月のシートを使います。
引き渡し一式（`python tools\leave_sheet\make_package.py`）は、プロジェクト直下の `超過勤務等命令簿（原本）.xlsx` を使います（氏名などが入ることがあるので Git には入れない）。

## 出勤・休暇管理データ での読み込みと照合

| ファイル | 内容 |
|---|---|
| `../leave_sheet/queries/休暇申請シート.pq` | 休暇申請シートを読むとき、表「超勤日別*」をつないで「超勤」の列に入れる |
| `../matching_excel/queries/超勤_月.pq` | 1人1か月で1行：所属長の確認（確認済み／確認待ち）、超過勤務のある日数、支給割合ごとの月の計、手当対象時間（30分未満切り捨て・30分以上切り上げ）、60時間超（+25・+15）。「超過勤務の読み込み」シートの A3 から |
| `../matching_excel/queries/超勤_日別.pq` | 登庁・退庁の時刻か超過勤務の時間がある日の1日1行。「超過勤務の読み込み」シートの AG3 から |
| `../matching_excel/macro/出勤・休暇管理データのマクロ.bas` の `TransferOvertime` | ［超過勤務を転記］：読み直して、B2 の月の確認済みの人の行を「超過勤務」（表 転記_月計）と「超過勤務の日別」（表 転記_日別）に値で写す。同じ人・同じ月は置き換える |

「超過勤務の日別」の照合の列（式）：

- 出勤の記録：その日の QR の出勤登録（照合結果シート）があれば「QR」、テレワークの予定（テレワーク_日別）があれば「テレ」。
- 休暇：承認済みの休暇（日別_自動）に「1日」があれば「1日」、ほかの休暇があれば「時間」。
- 注意：登庁時刻があるのに出勤の記録がない日（前日から日をまたいだ分だけの日は見ない）、1日の休暇の日、時間単位の休暇がある日（休暇の時刻と超過勤務の時刻の重なりまでは見ないので、時刻を確かめる）。

マクロ（VBA）はこのPCでは動かして確かめていません（スクリプトから取り込めないため）。同じ手順を PowerShell で動かして確かめています。
