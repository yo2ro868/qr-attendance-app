休暇申請システム 手順書（Microsoft Forms ＋ Power Automate）

Microsoft Forms で休暇を申請し、Power Automate で上司の承認を取り、結果を Excel の台帳（休暇申請台帳.xlsx）に記録する仕組みです。 台帳の集計を、別途引き渡す照合用Excelの「年次休暇」「月別取得時間」シートに写して使います。

職員 ──Forms「休暇申請」──▶ Power Automate ──▶ 台帳に追加（承認待ち）
                                   ├─▶ 承認者に承認依頼（Teams / Outlook）→ 承認・却下
                                   ├─▶ 台帳に結果を記録
                                   └─▶ 申請者に結果と残日数をメール
職員 ──Forms「残日数照会」──▶ Power Automate ──▶ 残日数をメールで返信
管理者 ── 台帳で「照合用Excel用に集計」を実行 ──▶ 照合用Excel に写す・貼り付ける

1. この一式に入っているもの・必要なもの

ファイル内容
手順書.htmlこの手順書
休暇申請台帳.xlsx台帳の空の様式（職員・年次休暇の持ち日数・申請・集計のシート）
スクリプト\1_申請を登録.txt申請を台帳に追加し、承認依頼の宛先と本文を作る
スクリプト\2_承認結果を記録.txt承認・却下を台帳に書き、申請者への結果メールの本文を作る

スクリプト\4_照合用Excel用に集計.txt照合用Excel に写す形で集計する（管理者が手で実行）

作業するPCに特別なソフトを入れる必要はありません。ブラウザで Microsoft 365 に入れれば作業できます。必要なのは次のものです。

  • Microsoft 365 の Forms・Power Automate・Excel（Web 版）・SharePoint（または OneDrive）
  • Excel（Web 版）の［自動化］タブ（Office Script）。タブが出ないときは、組織の Microsoft 365 管理者（情報システム担当）に有効化を確認してください。
  • フローで使うのは Microsoft Forms・Excel Online (Business)・承認・Office 365 Outlook の4つ（いずれも標準のコネクタ）
  • 別途引き渡す照合用Excel（出勤用ID と年次休暇の持ち日数をここから写します）

事前確認（最初に10分ほどで）

Office Script と、Power Automate からの実行が使えるかを先に確かめます。ここで止まる場合は、2 以降に進まずに情報システム担当に相談してください。

  1. Excel（Web 版）で新しい空のブックを作り、OneDrive に「スクリプト確認」などの名前で保存します。
  2. リボンに［自動化］タブがあることを確かめます。
  3. ［自動化］→［新しいスクリプト］を開き、中身を全部消して次を貼り付け、名前を「確認用」にして［実行］します。A1 に「Office Script OK」と出れば OK です。 
    function main(workbook: ExcelScript.Workbook) {
  workbook.getActiveWorksheet().getRange("A1").setValue("Office Script OK");
}
  4. A1 を消してから、Power Automate で［作成］→［インスタント クラウド フロー］（トリガー＝手動でフローをトリガーします）を作り、Excel Online (Business)「スクリプトの実行」を追加します。場所＝OneDrive for Business、ファイル＝スクリプト確認、スクリプト＝確認用 を選んで保存し、［テスト］で実行します。A1 に「Office Script OK」と出れば OK です。
  5. うまくいったら、確認用のフロー・スクリプト・ブックは削除してかまいません。
［自動化］タブがない、「スクリプトの実行」が見つからない、「データ損失防止（DLP）ポリシー」のエラーが出る、のどれかなら、ライセンスか管理者の設定で止められています。情報システム担当に「Office Scripts と、Power Automate からの Office Scripts の実行が有効か」「Forms・Excel Online (Business)・承認・Office 365 Outlook のコネクタを一緒に使えるか」を確認してください。

2. 台帳を置く

  1. 一式の 休暇申請台帳.xlsx を、SharePoint のドキュメントライブラリ（管理者だけが見られる場所）か、フローを作る人の OneDrive にアップロードします。氏名が入るので、共有の範囲は管理者に限ってください。
  2. Excel（Web 版）で開き、「職員」シートの表に、職員ごとに次を入れます。
    • メールアドレス：Forms に回答するときの組織のアカウント
    • 出勤用ID：照合用Excel の「職員名簿」シートと同じ ID
    • 氏名
    • 承認者メールアドレス：この人に承認依頼が届きます
  3. 「年次休暇の持ち日数」シートの表に、職員ごと・年ごとに1行入れます。
    • 合計（日）：その年に使える日数（繰越分＋本年分）。照合用Excel の「年次休暇」シートの「合計（自動）」の日数を写します。
    • 導入前の使用（日）・（時間）：この仕組みを使い始める前に、その年にすでに使った年次休暇。時間は「時間:分」（例 2:15）。
表（テーブル）の名前（職員・持ち日数・申請）と見出しの文字はスクリプトが使っています。列の追加や見出しの変更はしないでください。行を足すときは、表の最後の行のすぐ下に入力すると表が広がります。

3. Office Script を登録する

  1. 台帳を Excel（Web 版）で開き、［自動化］タブ →［新しいスクリプト］を開きます。
  2. 一式の スクリプト\1_申請を登録.txt をメモ帳で開き、全部選択（Ctrl＋A）してコピーし、スクリプトの編集画面の中身を全部消してから貼り付けます。
  3. スクリプト名を 申請を登録 に変えて保存します。
  4. 残りの3つも同じようにします（名前は 承認結果を記録／残日数を照会／照合用Excel用に集計）。
スクリプトは登録した人の OneDrive（ドキュメント ＞ Office Scripts）に保存されます。フローも同じ人のアカウントで作ってください。

4. フォームを作る

フォーム「休暇申請」

Forms で［新しいフォーム］を作り、［設定］を次のようにします。

  • 回答できるユーザー：組織内のユーザーのみ、名前を記録をオン（回答者のメールアドレスで本人を見分けます）
  • 1人につき1つの回答：オフ（何度でも申請できるように）
Q1 と Q4 の選択肢の文字は、下の表のとおり正確に入れてください。台帳の集計や残日数の計算に使います（かっこは全角）。

5. フロー「休暇申請」を作る

Power Automate で［作成］→［自動化したクラウド フロー］を選びます。各欄をクリックすると、前のアクションの値（「動的なコンテンツ」）を一覧から選べます。

  1. トリガー：Microsoft Forms「新しい応答が送信されるとき」（フォーム＝休暇申請）
  2. Microsoft Forms「応答の詳細を取得する」：フォーム＝休暇申請、応答 ID＝トリガーの「応答 ID」
  3. Excel Online (Business)「スクリプトの実行」：場所・ドキュメント ライブラリ・ファイル＝休暇申請台帳.xlsx、スクリプト＝申請を登録。引数は次のとおりです（未回答の質問は空のまま渡されます）。
    引数入れるもの
    responseIdトリガーの「応答 ID」
    submittedAt「送信時刻」
    email「回答者のメール」
    kindQ1 休暇の種類
    specialKindQ2 特別休暇の種別
    exemptDetailQ3 免除の内容
    unitQ4 取得の単位
    dayStart ／ dayEnd ／ daysQ5 開始日 ／ Q6 終了日 ／ Q7 日数
    timeDate ／ hours ／ minutes ／ timeRangeQ8 取得日 ／ Q9 時間 ／ Q10 分 ／ Q11 時刻
    reasonQ12 事由・備考
  4. 条件：3 の結果の found が true に等しい
    • いいえのとき：Office 365 Outlook「メールの送信 (V2)」で管理者あてに「職員表に登録のないメールアドレスから申請がありました」と送ります（本文に detailsHtml）。ここで終わり。
    • はいのとき：次の 5〜7 をこちらに入れます。
  5. 承認「開始して承認を待機」
    • 承認の種類：承認/拒否 - 最初に応答
    • タイトル：title　担当者：approverEmail　詳細：details
  6. Excel Online (Business)「スクリプトの実行」：スクリプト＝承認結果を記録
    引数入れるもの
    responseIdトリガーの「応答 ID」
    outcome承認の「結果」
    approver［式］タブに first(outputs('開始して承認を待機')?['body/responses'])?['responder/displayName']
    comments［式］タブに first(outputs('開始して承認を待機')?['body/responses'])?['comments']
    式の中の 開始して承認を待機 は 5 のアクションの名前です。名前を変えたときは、変えた名前（空白は _ に置き換え）にします。
  7. Office 365 Outlook「メールの送信 (V2)」：宛先＝6 の結果の email、件名＝subject、本文＝bodyHtml
承認者が応答しないまま 30 日たつと、フローは止まります（Power Automate の上限）。その申請は台帳で「承認待ち」のまま残るので、管理者が状況を直すか、申請し直してもらいます。

6. フロー「残日数照会」を作る

  1. トリガー：Microsoft Forms「新しい応答が送信されるとき」（フォーム＝残日数照会）
  2. 「応答の詳細を取得する」
  3. 「スクリプトの実行」：スクリプト＝残日数を照会、email＝「回答者のメール」、year＝照会する年
  4. 「メールの送信 (V2)」：宛先＝「回答者のメール」、件名＝subject、本文＝bodyHtml

7. 試しに申請してみる

  1. 台帳の「職員」表に自分を入れ、承認者も自分にします。「年次休暇の持ち日数」にも自分の行を入れます。
  2. 休暇申請フォームで、年次休暇の1日単位と時間単位を1件ずつ申請します。
  3. 台帳の「申請」表に行が増え、Teams か Outlook に承認依頼が届くことを確かめます。
  4. 承認すると、台帳の状況が「承認」になり、結果メールに残日数が書かれていることを確かめます。
  5. フローの実行履歴でエラーが出たら、どのアクションで止まったかを確認します（日付が読めない、などは台帳の「確認事項」列にも出ます）。
  6. 試しの行は、終わったら台帳の「申請」表から行ごと削除します。

8. 運用

  • 申請の取り消し：台帳の「申請」表で状況を「取消」に書き換えます（残日数・集計から外れます）。
  • 確認事項：年次休暇の時間が15分単位でない、介護時間・育児時間が30分単位でない、月をまたいでいる、承認待ちを含めると年次休暇が足りない、などは「確認事項」列と承認依頼の本文に出ます。申請は受け付けたうえで、承認するかどうかは承認者が判断します。
  • 残日数：年次休暇の残り ＝ 持ち日数 − 導入前の使用 − 承認済みの申請（1日＝7時間45分）。承認待ちは別に表示します。年は開始日の年で数えます。
  • 毎年1月：照合用Excel で前年の翌年繰越が決まったら、「年次休暇の持ち日数」表に新しい年の行（合計＝照合用Excel の年次休暇シートの合計）を足します。
  • 職員の異動：「職員」表の行を追加・修正します。承認者が変わったときは承認者メールアドレスを書き換えます。

9. 照合用Excel への反映

  1. 台帳の「集計」シートの B1 に年（西暦）を入れ、［自動化］タブから「照合用Excel用に集計」を実行します。
  2. A4 から下（年次休暇シート用）：本年使用（日）と本年使用（時間）を、照合用Excel の「年次休暇」シートの同じ出勤用ID・年の行の「本年使用（日）」「本年使用（時間）」の欄に写します。導入前の使用も含めた1年分の合計です。
  3. G4 から下（月別取得時間シート用）：見出しを除いてコピーし、照合用Excel の「月別取得時間」シートに行ごと貼り付けます（値の貼り付け）。同じ ID・年・区分の古い行は消してください（同じ行が2つあると上の行が使われます）。
    病気休暇・看護休暇の1日単位の申請は、1日＝7時間45分として時間にしています。

照合用Excel の出勤簿の日付の表（年次休暇・病気休暇などの欄）は、これまでどおり手で記入します。日ごとの内容は、台帳の「申請」表を開始日で並べ替えると確認できます。
