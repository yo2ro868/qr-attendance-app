休暇申請システム 手順書（Microsoft Forms ＋ Power Automate）

Microsoft Forms で休暇を申請し、Power Automate で上司の承認を取り、結果を Excel の台帳（休暇申請台帳.xlsx）に記録する仕組みです。 台帳の集計を、別途引き渡す照合用Excelの「年次休暇」「月別取得時間」シートに写して使います。

職員 ──Forms「休暇申請」──▶ Power Automate ──▶ 台帳に追加（承認待ち）＋「承認依頼」の通知
                                   ├─▶ 承認者が Power Automate の［承認］ページで承認・却下
                                   └─▶ 台帳に結果を記録 ＋「結果と残日数」の通知
職員 ──Forms「残日数照会」──▶ Power Automate ──▶「残日数」の通知

台帳の「通知」表 ──（OneDrive で同期）──▶ 組織のパソコンの「通知送信」──▶ Notes のメールで送る
管理者 ── 台帳で「照合用Excel用に集計」を実行 ──▶ 照合用Excel に写す・貼り付ける

組織では Teams・Outlook のメールを使えないため、お知らせは組織のパソコンの Notes から送ります。 Power Automate は送りたいお知らせを台帳の「通知」表に書くだけで、Notes が入っている組織のパソコンで動かす「通知送信」が、まだ送っていないものを Notes のメールで送ります。

ファイル内容

作業するPCに特別なソフトを入れる必要はありません。必要なのは次のものです。

  • Microsoft 365 の Forms・Power Automate・Excel（Web 版）・SharePoint（または OneDrive）
  • Excel（Web 版）の［自動化］タブ（Office Script）。タブが出ないときは、組織の Microsoft 365 管理者（情報システム担当）に有効化を確認してください。
  • フローで使うのは Microsoft Forms・Excel Online (Business)・承認 の3つ（いずれも標準のコネクタ）
  • 通知を送る組織のパソコン：Notes が入っていて、OneDrive の同期（エクスプローラーに OneDrive のフォルダが出るもの）が使えること
  • 別途引き渡す照合用Excel（出勤用ID と年次休暇の持ち日数をここから写します）

事前確認（最初に10分ほどで）

Office Script と、Power Automate からの実行が使えるかを先に確かめます。ここで止まる場合は、2 以降に進まずに情報システム担当に相談してください。

  1. Excel（Web 版）で新しい空のブックを作り、OneDrive に「スクリプト確認」などの名前で保存します。
  2. リボンに［自動化］タブがあることを確かめます。
  3. ［自動化］→［新しいスクリプト］を開き、中身を全部消して次を貼り付け、名前を「確認用」にして［実行］します。A1 に「Office Script OK」と出れば OK です。 
    function main(workbook: ExcelScript.Workbook) {
  workbook.getActiveWorksheet().getRange("A1").setValue("Office Script OK");
}
  4. A1 を消してから、Power Automate で［作成］→［インスタント クラウド フロー］（トリガー＝手動でフローをトリガーします）を作り、Excel Online (Business)「スクリプトの実行」を追加します。場所＝OneDrive for Business、ファイル＝スクリプト確認、スクリプト＝確認用 を選んで保存し、［テスト］で実行します。A1 に「Office Script OK」と出れば OK です。
  5. うまくいったら、確認用のフロー・スクリプト・ブックは削除してかまいません。
［自動化］タブがない、「スクリプトの実行」が見つからない、「データ損失防止（DLP）ポリシー」のエラーが出る、のどれかなら、ライセンスか管理者の設定で止められています。情報システム担当に「Office Scripts と、Power Automate からの Office Scripts の実行が有効か」「Forms・Excel Online (Business)・承認 のコネクタを一緒に使えるか」を確認してください。

2. 台帳を置く

  1. 一式の 休暇申請台帳.xlsx を、SharePoint のドキュメントライブラリ（管理者だけが見られる場所）か、フローを作る人の OneDrive にアップロードします。氏名が入るので、共有の範囲は管理者に限ってください。
  2. Excel（Web 版）で開き、「職員」シートの表に、職員ごとに次を入れます。
    • メールアドレス：Forms に回答するときの組織のアカウント
    • 出勤用ID：照合用Excel の「職員名簿」シートと同じ ID
    • 氏名
    • 通知先（Notes）：承認結果や残日数のお知らせを送る、本人の Notes のアドレス
    • 承認者メールアドレス：承認者の組織のアカウント（Power Automate の［承認］ページに依頼が出ます）
    • 承認者の通知先（Notes）：承認依頼のお知らせを送る、承認者の Notes のアドレス
  3. 「年次休暇の持ち日数」シートの表に、職員ごと・年ごとに1行入れます。
    • 合計（日）：その年に使える日数（繰越分＋本年分）。照合用Excel の「年次休暇」シートの「合計（自動）」の日数を写します。
    • 導入前の使用（日）・（時間）：この仕組みを使い始める前に、その年にすでに使った年次休暇。時間は「時間:分」（例 2:15）。
  4. 「設定」シートの B1 に、管理者（ご自身）の Notes のアドレスを入れます。職員表にない人からの申請や、通知先が空欄の人へのお知らせはここに届きます。
Notes のアドレスは、Notes でメールの宛先に入れるときと同じ書き方にします（例：山田 太郎/部署/組織 や、インターネット形式のアドレス）。
表（テーブル）の名前（職員・持ち日数・申請・通知）と見出しの文字はスクリプトが使っています。列の追加や見出しの変更はしないでください。行を足すときは、表の最後の行のすぐ下に入力すると表が広がります。

3. Office Script を登録する

  1. 台帳を Excel（Web 版）で開き、［自動化］タブ →［新しいスクリプト］を開きます。
  2. 一式の スクリプト\1_申請を登録.txt をメモ帳で開き、全部選択（Ctrl＋A）してコピーし、スクリプトの編集画面の中身を全部消してから貼り付けます。
  3. スクリプト名を 申請を登録 に変えて保存します。
  4. 残りの3つも同じようにします（名前は 承認結果を記録／残日数を照会／照合用Excel用に集計）。
スクリプトは登録した人の OneDrive（ドキュメント ＞ Office Scripts）に保存されます。フローも同じ人のアカウントで作ってください。

5. フロー「休暇申請」を作る

Power Automate で［作成］→［自動化したクラウド フロー］を選びます。各欄をクリックすると、前のアクションの値（「動的なコンテンツ」）を一覧から選べます。

  1. トリガー：Microsoft Forms「新しい応答が送信されるとき」（フォーム＝休暇申請）
  2. Microsoft Forms「応答の詳細を取得する」：フォーム＝休暇申請、応答 ID＝トリガーの「応答 ID」
  3. Excel Online (Business)「スクリプトの実行」：場所・ドキュメント ライブラリ・ファイル＝休暇申請台帳.xlsx、スクリプト＝申請を登録。引数は次のとおりです（未回答の質問は空のまま渡されます）。
    引数入れるもの
    responseIdトリガーの「応答 ID」
    submittedAt「送信時刻」
    email「回答者のメール」
    kindQ1 休暇の種類
    specialKindQ2 特別休暇の種別
    exemptDetailQ3 免除の内容
    unitQ4 取得の単位
    dayStart ／ dayEnd ／ daysQ5 開始日 ／ Q6 終了日 ／ Q7 日数
    timeDate ／ hours ／ minutes ／ timeRangeQ8 取得日 ／ Q9 時間 ／ Q10 分 ／ Q11 時刻
    reasonQ12 事由・備考
  4. 条件：3 の結果の found が true に等しい
    • いいえのとき：何も入れません（管理者へのお知らせは、スクリプトが台帳の「通知」表に書いています）。
    • はいのとき：次の 5〜6 をこちらに入れます。
  5. 承認「開始して承認を待機」
    • 承認の種類：承認/拒否 - 最初に応答
    • タイトル：title　担当者：approverEmail　詳細：details
    • 詳細オプションの「通知を有効にする」：いいえ（Outlook のメールは使わないため。お知らせは Notes で届きます）
  6. Excel Online (Business)「スクリプトの実行」：スクリプト＝承認結果を記録
    引数入れるもの
    responseIdトリガーの「応答 ID」
    outcome承認の「結果」
    approver［式］タブに first(outputs('開始して承認を待機')?['body/responses'])?['responder/displayName']
    comments［式］タブに first(outputs('開始して承認を待機')?['body/responses'])?['comments']
    式の中の 開始して承認を待機 は 5 のアクションの名前です。名前を変えたときは、変えた名前（空白は _ に置き換え）にします。

メールを送るアクションは入れません。承認依頼と結果のお知らせは、スクリプトが台帳の「通知」表に書き、7 の「通知送信」が Notes で送ります。

承認者は、お知らせ（Notes）を受け取ったら、ブラウザで https://make.powerautomate.com を開き、左のメニューの［承認］（見当たらなければ［その他］の中）の「受信済み」から承認・却下します。

承認者が応答しないまま 30 日たつと、フローは止まります（Power Automate の上限）。その申請は台帳で「承認待ち」のまま残るので、管理者が状況を直すか、申請し直してもらいます。

6. フロー「残日数照会」を作る

  1. トリガー：Microsoft Forms「新しい応答が送信されるとき」（フォーム＝残日数照会）
  2. 「応答の詳細を取得する」
  3. 「スクリプトの実行」：スクリプト＝残日数を照会、responseId＝トリガーの「応答 ID」、email＝「回答者のメール」、year＝照会する年

これだけです。返事のお知らせは、スクリプトが台帳の「通知」表に書き、7 の「通知送信」が Notes で送ります。

7. Notes で通知を送る（組織のパソコン）

台帳の「通知」表に書かれたお知らせを、組織のパソコンの Notes から送ります。Notes が入っている、ふだん使っているパソコンで設定します。

準備

  1. OneDrive の同期：エクスプローラーの左側に「OneDrive - （組織名）」があり、その中に 休暇申請台帳.xlsx が見えることを確かめます。 見えないときは、ブラウザの OneDrive で［同期］を押すか、Windows の OneDrive アプリに組織のアカウントでサインインします。 台帳を右クリックし、［このデバイス上に常に保持する］にしておきます。
  2. 通知送信のフォルダを置く：一式の 通知送信 フォルダを、パソコンのドキュメントなどにコピーします（OneDrive の中でなくてかまいません）。
  3. Notes を起動して、サインインしておきます。

動くかを確かめる（1 → 2 → 3 の順に）

ファイル（ダブルクリック）することうまくいったとき
1_テスト送信.cmd宛先を聞かれるので、自分の Notes のアドレスを入れて EnterNotes に「通知送信のテスト」が届く
2_台帳の確認.cmd同期している台帳を読み、送る予定のお知らせを表示する（送信はしない）「台帳: （場所）」と、お知らせの件数や一覧が表示される
3_通知送信を開始.cmd5 分おきに台帳を確かめ、まだ送っていないお知らせを Notes で送り続ける「5 分おきに確認します」と表示され、黒いウィンドウが開いたままになる
  • 初めて 3 を動かしたときは、その時点で台帳にあるお知らせ（試しに書かれたものなど）は送らずに「送信済み」として記録します。それ以降に増えたものだけを送ります。
  • 3 の黒いウィンドウは最小化して開いたままにします。閉じると止まります。
  • 送った記録は通知送信のフォルダの 送信済み.txt、動きの記録は 通知送信ログ.txt に残ります。送信済み.txt は消さないでください（消すと、次に動かしたときにその時点の分を送らずに記録し直します）。

パソコンを起動したら自動で動かす

  1. 3_通知送信を開始.cmd を右クリック →［ショートカットの作成］。
  2. Windows キー＋R を押し、shell:startup と入力して Enter（スタートアップのフォルダが開きます）。
  3. 作ったショートカットを、そのフォルダに移します。ショートカットのプロパティで「実行時の大きさ」を「最小化」にしておくと邪魔になりません。

Notes より先に起動して Notes に接続できないときは、Notes にサインインするまで 1 分おきに待ちます。お知らせは、パソコンの電源が入っていて Notes にサインインしている間に送られます（休日などに止まっていた分は、次に動いたときにまとめて送られます）。

表示対処
Notes に接続できませんNotes を起動してサインインしてから、もう一度実行します。それでも出るときは、通知送信ログ.txt と画面の表示を控えて相談してください

Notes で「パスワードの入力」が出る入力すると続きます。毎回出るときは、Notes のセキュリティの設定で「Notes に基づくほかのプログラムとパスワードを共有」をオンにできるか、情報システム担当に確認してください
宛先が空欄なので送りません台帳の「設定」シートの B1（管理者の通知先）に Notes のアドレスを入れます

8. 試しに申請してみる

  1. 台帳の「職員」表に自分を入れ、承認者も自分にします。「年次休暇の持ち日数」にも自分の行を入れます。
  2. 休暇申請フォームで、年次休暇の1日単位と時間単位を1件ずつ申請します。
  3. 台帳の「申請」表と「通知」表に行が増え、数分後に Notes に承認依頼のお知らせが届くことを確かめます。
  4. Power Automate の［承認］ページで承認すると、台帳の状況が「承認」になり、Notes に結果のお知らせ（残日数つき）が届くことを確かめます。
  5. 残日数照会フォームにも回答し、Notes に残日数のお知らせが届くことを確かめます。
  6. フローの実行履歴でエラーが出たら、どのアクションで止まったかを確認します（日付が読めない、などは台帳の「確認事項」列にも出ます）。
  7. 試しの行は、終わったら台帳の「申請」表から行ごと削除します（「通知」表の行は残しておきます）。

9. 運用

  • 申請の取り消し：台帳の「申請」表で状況を「取消」に書き換えます（残日数・集計から外れます）。
  • 確認事項：年次休暇の時間が15分単位でない、介護時間・育児時間が30分単位でない、月をまたいでいる、承認待ちを含めると年次休暇が足りない、などは「確認事項」列と承認依頼の本文に出ます。申請は受け付けたうえで、承認するかどうかは承認者が判断します。
  • 残日数：年次休暇の残り ＝ 持ち日数 − 導入前の使用 − 承認済みの申請（1日＝7時間45分）。承認待ちは別に表示します。年は開始日の年で数えます。
  • 毎年1月：照合用Excel で前年の翌年繰越が決まったら、「年次休暇の持ち日数」表に新しい年の行（合計＝照合用Excel の年次休暇シートの合計）を足します。
  • 職員の異動：「職員」表の行を追加・修正します。承認者が変わったときは、承認者メールアドレスと承認者の通知先（Notes）を書き換えます。
  • 通知送信：通知送信を動かしているパソコンが止まっている間のお知らせは、次に動いたときにまとめて送られます。届かないという問い合わせがあったら、通知送信のフォルダの「通知送信ログ.txt」を見ます。

10. 照合用Excel への反映

  1. 台帳の「集計」シートの B1 に年（西暦）を入れ、［自動化］タブから「照合用Excel用に集計」を実行します。
  2. A4 から下（年次休暇シート用）：本年使用（日）と本年使用（時間）を、照合用Excel の「年次休暇」シートの同じ出勤用ID・年の行の「本年使用（日）」「本年使用（時間）」の欄に写します。導入前の使用も含めた1年分の合計です。
  3. G4 から下（月別取得時間シート用）：見出しを除いてコピーし、照合用Excel の「月別取得時間」シートに行ごと貼り付けます（値の貼り付け）。同じ ID・年・区分の古い行は消してください（同じ行が2つあると上の行が使われます）。
    病気休暇・看護休暇の1日単位の申請は、1日＝7時間45分として時間にしています。

照合用Excel の出勤簿の日付の表（年次休暇・病気休暇などの欄）は、これまでどおり手で記入します。日ごとの内容は、台帳の「申請」表を開始日で並べ替えると確認できます。
